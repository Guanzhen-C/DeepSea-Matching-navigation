# MBES–SSS 特征前端与混合消融验证（2026-09-15）

## 结论

本轮实现采用与水下可观性相符的特征前端：IMU/DVL/深度计传播，侧扫
8 行图像通过运动初值约束的 KLT 亚像素跟踪，再把轨迹提升到产生像素的
同源 MBES XYZ，只提供沿航向的一维位置投影观测。横向、航向、深度、
滚转和俯仰不会由这条特征观测直接修改。`feature` 模式默认不再把直接
点到自建局部地图的 MBES 配准写回 Local 状态；MBES 仍进入特征几何、
局部地图、因子图和 Global。显式开关可以恢复该直接写入，用作混合消融。

正式特征替代版在 7 组 60 m 跨区域/跨随机种子实验中的平均 RMSE 为
0.356 m，DR 为 0.403 m，直接 MBES 前端为 0.439 m，分别改善 11.8% 和
19.1%；每一组 RMSE 都优于两种基线。1 km 同源回归的 RMSE 为 3.788 m，
DR 为 4.390 m，直接 MBES 前端为 5.374 m。它仍是仿真实验前端，不构成
完整路线或海试精度声明。

## 算法链路

1. 每个物理 ping 单侧同时产生 8 行，标准模式行距 0.15 m；5 Hz、
   1.5 m/s 时相邻 ping 前进 0.30 m，理论覆盖重叠 0.90 m。
2. 强度做对数压缩、距离趋势归一化和局部对比度处理，GFTT 提取角点。
3. IMU+DVL 给出包含滚转、俯仰、深度和安装杆臂的完整 SE(3) 初值；
   金字塔 KLT 以前后向一致性检查获得亚像素轨迹。
4. 图像轨迹回投到产生像素的同源 MBES XYZ，确定性 RANSAC 只拟合
   预测附近的误差状态，而不是把有俯仰的点云压成平面刚体。
5. 连续 Cauchy 一致性权重限制周期纹理假解的影响，不设置状态创新
   的硬切断门限。
6. 4 个不同物理 ping 形成一个不重复使用回波的相对约束。最终滤波
   接口是标量 `axis_xy · position_xy`；状态投影器从数学上禁止该观测
   直接改变横向位置、姿态和深度。
7. 默认不把直接 MBES 点到局部地图配准写入 Local 状态，以免前向条带
   的自建地图形变反过来污染里程计；`--feature-retain-direct-mbes-state-update`
   可恢复这一路径用于消融。
8. MBES 地图/描述子、Global UTAN/cohort PF、GTSAM 因子图和
   `map -> odom` 输出链保持原有职责。

## GPU 加速验证

函数级剖析表明慢点不是 GFTT 或双向 KLT，而是每个相邻 ping 串行求解
256 个 RANSAC 运动假设。正式实现通过 `--feature-compute-backend cuda`
将全部假设以 float64 一次批量送入 PyTorch CUDA；选出的内点集仍由原有
CPU 双精度代码完成全内点重拟合、可观性检查、协方差计算和 ESIKF 更新。
显式 `cuda` 在设备不可用时直接报错，`auto` 才允许并记录 CPU 回退。

路线 30 km、种子 31、60 m、完全相同输入的 CPU/CUDA 对照结果如下：

| 指标 | CPU | CUDA | 加速比 |
|---|---:|---:|---:|
| 平均 RANSAC | 54.25 ms | 6.42 ms | 8.45x |
| 平均完整特征配对 | 57.65 ms | 9.88 ms | 5.84x |
| 完整 A/B 回放墙钟时间 | 24.78 s | 15.29 s | 1.62x |

CUDA 共执行 199 次 RANSAC，CPU 回退 0 次。两次逐采样误差 CSV 完全
相同，最大绝对差为 0；Feature RMSE/最终误差均为
0.294594/0.508474 m。完整回放还包含传感器生成和 Direct 对照，因此
1.62x 是端到端结果，不是只报告 GPU 内核时间。4096 个同源回波的栅格
构建同时改为等价向量化，平均由约 59 ms/ping 降至约 8 ms/ping；像素
对应的物理 XYZ 归属规则未改变。

上述 199 次调用使用 Isaac Sim 6.0 的同一 Python 环境。由于旧版长程
Isaac 进程仍按要求保留运行，并发启动的第二个最小 SimulationApp 在
90 s 初始化超时前尚未执行到 PyTorch 运算，所以该项不计为通过；完整
Isaac+CUDA 同进程冒烟验证留到下一次正式重启执行，不能由轻量回放替代。

## 1 km 前端职责消融

路线 30 km、种子 31、真值初始化且使用完全相同的传感器序列时：

| 方法 | RMSE | P95 | 最大值 | 最终误差 |
|---|---:|---:|---:|---:|
| DR | 4.390 | 6.275 | 6.507 | 6.384 |
| 直接 MBES | 5.374 | 8.553 | 8.827 | 8.224 |
| Feature + 直接 MBES 混合消融 | 4.773 | 7.427 | 8.207 | 6.549 |
| Feature 替代版 | **3.788** | **5.020** | **5.299** | **4.938** |

Feature 替代版相对 DR/直接 MBES/混合消融的 RMSE 分别改善约
13.7%/29.5%/20.6%。3332 次相邻配对接受 3330 次，形成 1109 次子帧
滤波更新且没有滤波更新失败；平均内点率为 47.6%，平均点配准残差为
0.235 m。分量统计表明它没有直接修改航向：航向 RMSE 0.346 度，与 DR
的 0.349 度接近；主要收益来自沿路线位置分量。横向和航向仍会漂移，
因此该结果不能解释为 Local 已全局有界。原始数据见
`feature_only_klt_alongtrack_ab_start30km_1km_20260915.json` 及同名 CSV；
混合消融见 `hybrid_klt_scalar_alongtrack_ab_start30km_1km_20260915.json`。

## 低分辨率负对照

关闭亚栅格散射、只使用 USGS 5 m 实测强度时，199 次相邻配对中 152 次
因几何内点不足而拒绝，仅形成 4 次滤波更新。Feature/DR/直接 MBES 的
RMSE 为 0.352/0.357/0.360 m，说明低纹理输入会基本退化为 DR 传播，
而不会以“匹配调用成功”冒充有效强度约束。原始数据见
`feature_only_measured5m_negative_control_start30km_60m_20260915.json`。

## 亚栅格纹理幅值敏感性

路线 30 km、种子 31 的 60 m 同源测试结果如下。0.09/0.18/0.27 三档均
接受 199/199 次配对并形成 66 次更新，Feature RMSE 分别为
0.298/0.295/0.297 m；对应终点误差为 0.514/0.508/0.515 m。只要仿真中
存在传感器分辨率尺度的稳定空间纹理，结果对这三档具体幅值不敏感；但
幅值为零时会因 5 m 公共栅格缺少亚米纹理而退化。这是仿真输入边界，
不是对实物侧扫信噪比的验证。

## 数据真实性边界

- 地形、低频强度包络和全图路线来自 USGS Monterey Canyon 公共实测
  产品；底图最终网格分辨率为 5 m。
- V2 文档给出的标准模式沿航向采样是 0.15 m。5 m 公共栅格不含这一
  尺度的真实纹理，无法单独验证亚米级特征里程计。
- `--subgrid-reflectivity-amplitude 0.18` 添加的是世界固定、带限、零均值
  的未分辨沉积物散射模型。它保留实测强度作为低频包络，但亚栅格部分
  是明确标注的合成数据，不得表述为实测侧扫图。
- `0` 保持旧仿真逐值不变；指标 JSON 会记录振幅和来源说明。
- 仿真不包含相干相位、折射、多径、完整水柱散射和真实换能器标定，
  结果不是海试或水文测量精度。

## 复现

快速确定性 A/B：

```bash
/home/cgz/.conda/envs/isaacsim-6.0/bin/python \
  standalone/feature_frontend_measured_replay.py \
  --survey-start-distance-m 30000 \
  --survey-segment-distance-m 120 \
  --subgrid-reflectivity-amplitude 0.18 \
  --feature-compute-backend cuda \
  --metrics demo/large_scale_slam/feature_frontend_replay.json
```

Isaac Sim UI/全图候选：

```bash
standalone/run_v2_feature_hybrid_slam_isaac.sh
```

该启动器使用 GTSAM 增量固定滞后图、cohort 粒子地形跟踪、3-D BBS
验证和 `map -> odom` 软输出校正；可追加 `--headless`。在现有旧版
长程 Isaac 进程结束前，不并发启动第二实例，以避免内存/显存争用造成
“Isaac Sim Python 无响应”。为与上述前端实验一致，启动器从路线 30 km
处开始并使用仿真真值初始化；这只用于评估相对里程计，不是可部署初始
条件，也不参与后续时刻的估计。
