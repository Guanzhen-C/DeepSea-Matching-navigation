千岛湖复数侧扫特征辅助导航实验（当前在验证，不是稳定版验收）

一、当前用户决定
最终目标是侧扫声呐信息对地形地貌匹配导航确实有效，不是仅生成图像或跑通接口。
用户最新明确“那就不加这个去噪”：取消新增二次去噪。
已固定的实测去噪幅度场继续作为构景外观来源；原冻结网络/参数不修改。
当前链路：按位姿产生I/Q回波 → 正常LFM脉冲压缩 → 当前/历史观测按Local短时位姿拼接 → 特征匹配。
重叠扫描仅作普通平均拼接，不额外运行Huber幅度去噪、IQ神经网络或窄带前级滤波。

二、信号模型与真实边界
1. 参数读取依据：处理数据中保存的SysPara，c=1480m/s、f0=450000Hz、解调参考451800Hz、
   BeamSigFs=37650Hz、T=.005s、Kr=-6000000Hz/s（带宽30000Hz）、8同步沿航向行、间距.15m。
2. 新增PointScattererIQSimulator是单次散射、停止-跳跃的等效波束复数基带模型。
   世界网格散射相位固定，不在每个ping重抽；路径时延2R/c，脉冲卷积和接收机解调参考明确。
   正确频移约定由“延迟RF波形再LO解调”的独立解析测试核对，避免重复计算载频偏置。
3. 去噪场只是已经观测过的幅度外观代理，不是标定散射系数，不能再强加相同TVG/衰减。
4. 模型不包含阵元级接收波束形成、完整波动方程、多途或地形遮挡；不是专业全声场仿真。
   幅度图不能恢复真实原相位；当前是明确标注的仿真I/Q，不是声学所实测原始I/Q。
5. 附加热噪声/相干条带是显式合成假设，尚未辨识成设备真实电子干扰。
6. 海底几何仅用于仿真器生成声波路径，不交给纯侧扫估计器。导航没有测深XYZ、DOA或高度似然。

三、构图与匹配
1. 每个物理ping提供两侧各8行。脉冲压缩之后按距离样本进行功率汇聚，形成导航用512格/侧。
   原生复数记录仍保留，导航栅格化不是给原始文件降采样或改写MAT。
2. 最近150个实际收到的ping进入局部窗口，按Local位姿对齐；只用过去和当前，不读取未来记录。
3. 只在相邻有效接收样本之间作距离插值，不延伸到缺测场，中央水柱不能凭空填成地形。
4. LoFTR产生局部特征对应；随后进行侧扫扫描平面几何一致性验证。
   不是光流、直接强度相关或将斜距当成水平距离的二维刚性配准。
5. 未知地物高度时，沿航向/航向信息和横向零空间分开处理；不制造虚假的横向绝对约束。
6. 连续独立窗口由原cohort粒子跟踪器确认，再进入原GTSAM固定滞后优化和map→odom软校正。
   frozen图API沿用旧terrain_prior入口验证通用平面先验，但新增因子随后如实标为side_scan_feature_prior。
   原冻结后端源文件没有改；这不代表加入了测深观测。

四、已保留的失败与改进证据
1. f34a5de保存原纯侧扫调查版；原生稀疏射线图中有效像素仅约19%，特征匹配未通过。
2. complex_sss_history150_v1完成150实际连续I/Q回波、冻结网络推理和子图导出。
   仿真包络RMSE：原始.0042623、额外固定网络.0217090，额外网络反而较差，明确不采用。
   该网络固定负频带前级与新仿真完整LFM波形有域失配；原实测去噪结果不因此被否定。
3. 同一I/Q窗口的LoFTR诊断：含噪、无额外去噪图产生105对对应，42对扫描平面内点。
   这只是匹配证据，不是导航RMSE成功，也不是全局未知初值定位验证。
4. 第一个在线400m候选在第450个ping首次确认先验时因旧因子名字限制退出；原输出与日志保留。
   已修正适配层并补充真实GTSAM连续同步/固定滞后/横向零空间测试。
5. 同时独立RF解析测试发现并修正了复基带载频偏置的重复相位计算。
6. v2已完成400m（最后声呐采样399.9599m），1516声呐、25000 IMU、2500 DVL、5000压力事件全部处理。
   三维位置RMSE：DR 4.268549m、Local 3.257129m、Global 2.330887m。
   P95：6.912293/5.588978/3.702692m；终点误差7.099136/5.741361/3.614345m。
   10次地图匹配9次通过，连续独立窗口确认后7条真实侧扫先验进入GTSAM。
   发布Global对DR的RMSE降低约45.4%，Local降低约23.7%。不是全程平均或多随机种子统计。
   首150个ping原生复数观测保留为first_native_received_IQ.npy，未把图像当测量、未覆盖原MAT。
7. 当前仅短程正面证据；尚需完整梳形转弯/往返、较长航程、其它种子与初值误差测试。
   扫描平面没有独立横向绝对约束，不能宣称平坦区/未知初值/全部海域都已验证有效。
   传感器生成方式与旧联合实验不同，二者结果不能作为“只更改了一个算法”的因果消融。

五、复现命令
env OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 \
  .venv-sonar-denoise/bin/python standalone/RunPureSideScanFeatureShort.py \
  --experiment output/real_sonar/qiandao_fullframe_joint_comb_20261106_v2 \
  --out output/real_sonar/qiandao_fullframe_joint_comb_20261106_v2/自行选择新结果目录 \
  --distance-m 400 --observations complex_IQ --feature-matcher LoFTR
输出目录必须新建，不覆盖旧实验。程序没有内存上限设置；原联合长程PID574641不重启。
