# 阶段研究材料说明与证据索引

项目：基于迁移学习的海底地形重建与高精度定位技术研究。整理日期：2026年10月2日。

## 一 材料用途

本套材料补齐1月至9月任务安排，以及3月调研、5月超分、6月重定位、7月声呐里程计四份报告。它们是本次整理形成的研究成果正文与实施依据，任务归属月份不是实验发生日期。后续可以按数据准备、算法实现、对照测试与验收步骤执行，并用实际记录补充结果。

报告将文献调研、已实现系统、已有实验和待实施研究分别表述。已有仿真结果采用归档文件，不编造训练权重、海试或实机板卡结果。最终项目验收还需依据正式任务书与现场实施记录。

文献检索采用作者论文、发表机构、官方工程和原始数据发布页面等一手来源，选取与任务相关的代表性文献，不声称穷尽全部公开资料。只有摘要可访问的文献用于方向判断，不据此填写未核实的实现细节。2026年资料及9月实验作为后续补充，不伪写成早期月份已经获得的证据。

## 六 评价指标

同步位置误差e_k=‖p̂_k−p_k‖₂；RMSE=√(Σe_k²/N)，MAE=Σe_k/N。P95为95百分位，不是95%的定位成功率。最大值与最终值分别记录，不能用最终值代表全程精度。

Local相对精度采用SE(3)相对位姿误差：E_ij=(T_i⁻¹T_j)⁻¹(T̂_i⁻¹T̂_j)。报告平移范数与旋转角的RMSE，并区分100 m、1 km及10 km间隔。旧的世界坐标位移差不对固定航向规范偏差保持不变，因此不替代SE(3)口径。

在线Global、全历史iSAM2诊断、最终固定滞后轨迹是不同输出，分别计算。超分使用高程、坡度、曲率和测量一致性指标；导航效果需固定真值及观测流后单独评价。
