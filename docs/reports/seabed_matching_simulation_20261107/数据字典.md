# 仿真报告数据字典

## 一、共同约定

1. 坐标与单位。位置单位米，时间单位秒，误差为未作事后刚体对齐的三维欧氏距离。千岛湖坐标为声明原航速与姿态假设建立的名义局部坐标，不是独立实测地理真值。
2. DR为航位推算，Local为声呐局部里程计，Global为该时刻实际发布的位置。HIL的board为板载输出，pc或native为原PC参考，二者不能交换。
3. `distance_m`为仿真真值累计航程，用于事后统计和绘图，不代表该距离作为传感器观测传给估计器。
4. 表内全程RMSE为完整采样集合的平方均值开根，P95为该集合误差的95分位值。100 m各区间的RMSE不可直接取算术均值代替全程RMSE。

## 二、完整误差CSV

### 1. 海湖板载

`lake_hil_errors_full.csv`和`sea_hil_errors_full.csv`的列为：

| 列 | 含义 |
|---|---|
| `timestamp_s` | 原始共同仿真时间戳 |
| `distance_m` | 同时刻累计航程 |
| `board_dr_error_m` | 板载DR三维位置误差 |
| `pc_dr_error_m` | 原PC DR三维位置误差 |
| `board_local_error_m` | 板载Local三维位置误差 |
| `pc_local_error_m` | 原PC Local三维位置误差 |
| `board_global_error_m` | 板载在线Global三维位置误差 |
| `pc_global_error_m` | 原PC在线Global三维位置误差 |

板载误差重新由实际保存XYZ减真值XYZ计算，与原误差列及完整审核指标核对。PC列使用共同时间轴上的原PC参考误差，并与原完整审查指标核对。HIL没有宣称板卡与PC轨迹逐值相同。

### 2. 千岛湖纯侧扫

| 列 | 含义 |
|---|---|
| `timestamp_s`、`distance_m` | 原物理ping时间、仿真累计航程 |
| `dr_error_m`、`local_error_m` | 四组逐值相同的DR和Local误差 |
| `legacy_no_loops_error_m` | 旧条带、无回环Global |
| `legacy_loops_control_error_m` | 旧条带、有回环Global，原执行源逐值控制 |
| `projected_no_loops_error_m` | 新来源投影、无回环Global |
| `projected_loops_error_m` | 新来源投影、有回环Global，当前选定组合 |

四组使用同一份完整导航观测，而非分别重新生成不同噪声。Global的差异属于算法差异；DR、Local输入和结果在四组中逐值相同。

## 三、完整轨迹压缩CSV

### 1. 海湖HIL

列包含`timestamp_s`、`distance_m`、`truth_x_m/y_m/z_m`、`dr_x_m/y_m/z_m`、`local_x_m/y_m/z_m`、`global_x_m/y_m/z_m`，后续列为三路板载误差、三路原PC误差、`roundtrip_s`和`arrival_lateness_s`。坐标列中的DR/Local/Global均为板载实际输出。

`roundtrip_s`包括通信和处理，不是纯网络传播时延；`arrival_lateness_s`反映输出相对于源仿真时间的到达迟到，不能把持续累积的迟到解释为已保持实时。

### 2. 千岛湖

列包含时间、航程、真值XYZ以及新组合DR/Local/Global各XYZ。真值只在定位结束后的报告处理程序读取。该文件没有全部回环对应点或全程原生I/Q；真实图因子与回环过程另见`evidence/qiandao/`。

## 四、100 m分段统计

`start_m`为区间起点，`end_m`为区间上界；按`floor(distance_m/100)`分箱，左闭右开。`samples`为区间样本数，`channel`为对应通道，后续为区间RMSE、中位数、P95、最大和最后一个样本误差。

这些分段是同一次完整试验的描述性统计，不是独立重复试验，不应用各段数量替代实验重复次数或据此构造独立样本置信区间。

## 五、来源与哈希

`evidence/export_manifest.json`分别列出本机来源与导出产物，文件哈希验证文件字节身份，不自动证明观测模型正确。完整在环、场景名义坐标、去噪保真和实时性限制需结合对应审核JSON解释。

原始超限采集包未包含在本目录；完整轨迹的gzip不代表这些原始声学数据也已上传。不要将CSV中用于评价的真值字段重新喂给导航算法。
