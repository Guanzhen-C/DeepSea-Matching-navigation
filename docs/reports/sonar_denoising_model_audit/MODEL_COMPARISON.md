# 56M 与实际 NX 小模型对照

以下各值注明口径，不能用“缺失”行的任意候选值填表，也不把不同硬件、相同数据却不同计时范围的数据当作速度倍数。证据 [G56、W、E、J、V56/V7、F56](README.md#证据及状态)。

| 指标 | 56M 离线大模型 | 实际板端小模型 |
|---|---|---|
| 工程身份 | `random_adapted_56M`，`NoFIRSonarMWCNN(96)`，混合适配 checkpoint 8000 | `LateSpectralJointBeam(128) + WeakEchoVerifier`，冻结 `signed_response@200 / range_balanced_identity / weak_verifier_original` |
| 参数量 | **56,083,513**，G56 `records/model_architecture_check.json` 和 F56 全段回执 | **7,518,563**（约为大模型 13.4%），本审查严格 CPU 加载三权重计数 |
| 模型权重大小 | 推理 `model_inference_fp32.pt` 224,352,756 B（213.96 MiB），文件 SHA-256 `d33697c1d01a763477f024cb70a798614ba40149ff520c4e15a4b5e3e096c06f`；适配训练 checkpoint 不作部署权重比较 | 3 文件合计 30,112,330 B（28.72 MiB）；分项与哈希见 README，包含 checkpoint 容器开销 |
| 网络结构 | 编码—解码 3 次二维 Haar，通道 96/192/384/768，同尺度残差，四域仿射；无显式逐 ping 循环状态。 | 3 次一维距离 Haar、4 个有状态尺度 128/256/384/512，8 同舷束联合，隔离因果状态与晚期频谱，另有幅度父读出与弱回波保护。 |
| 输入通道及输出 | 3 特征：支持归一化的局部 $\log A$ 对比度、距离相位差实/虚；掩码和域另给。每次推断二维原生核心上的标量 log 增益。 | I/Q 逐 ping；4 因果特征＋24 同 ping 谱特征/束，6 crossfit 辅助通道，掩码、4 个状态另给。输出一 ping 的 16×R log 增益和 next states。 |
| 分块/上下文 | 工作站 V56 标准核心 96×768，Halo (168,200)、对齐 8；NX TensorRT F56 核心 192×768，内部最大范围 528×1168。训练核心最大 96×384，数值输出与可视化后处理分开。 | R12189 / R12721 全原生行，不分块无 Halo；距离右填充最小至 8 倍数。时间一步一 ping，不用未来；past4 和递归状态不同。 |
| FLOPs/MACs | **尚无同口径记录**；须注明每核心/含 Halo/全航次、前处理与网络分别计 | **尚无同口径记录**；须注明每 ping 16 束、R、四状态实际尺寸；分开统计 FFT、投影、图运行、恢复 |
| 推理精度和模型制品 | PC PyTorch FP32，NX 有 PyTorch FP32 和 TensorRT FP32；本机 ONNX 224,380,143 B。 | PC PyTorch FP32 / ORT FP32；NX TensorRT FP32 + CUDA Graph，两 ONNX/plan 大小见 README；无 FP16、INT8 用于本次 HIL 的证据。 |
| 工作站耗时 | V56 四 worker 的混合评估记录（含不同模型、人工噪声评分和实采），各 1,885.23–2,082.79 s，不能当作该 56M 单模型等输入全段耗时。 | V7 98.15 s：同权重实采全段 2,020 ping 推理、写图与核验的混合计时（不含初始图构建），非纯推理、非 PC CPU、非 Jetson。 |
| NX 实测耗时 | TensorRT 全段 **4018.34 s**（离线）；历史 PyTorch 全段 4171.44 s。 | H0 模型段 P99 **132.85 ms/ping**；H5 模型 P99 130.78 ms，板端去噪段 P99 240.00 ms；R 实采双臂含导航及网络 1000.51 s。无该小模型板端同口径纯整段离线耗时。 |
| 峰值内存 | V56 工作站评估 worker 各 3,322,837,504 B（Torch 分配峰，混合）；NX TensorRT 的多种内存口径见性能档，旧 PyTorch 2,871,822,848 B CUDA 分配峰。 | **缺包络相同的实测数据**；权重字节、plan 容量、CUDA 总 RAM 都不是峰值。 |
| 去噪质量 | 受控人工增量全 16 束对数 RMSE 0.24448→0.12894、32 组合/285,696,000 个有效评分值，参考是未叠加该增量的实采，不是理想干净。同色表全幅仅作视觉证据。 | T1/T2/T3 有开发配对及保护账本；V7 同权重有原生全幅和 1:1 局部；H0/H5/R 有下游 A/B。**没有与左栏同源同噪同掩码的独立测试 RMSE**，不可据开发结果给出对 56M 的质量保留百分数。 |
| 纹理保持 | V56 无新增扰动身份自扰动 RMS 0.00739（上一 56M 为 0.01528、仅公共预训练为 0.00469），不是实际水底真值评估。 | 保护头的幅度乘子范围已验证；V7 与 T3 是图像或开发证据，不代表纹理保真认证。待独立地物/弱回波/阴影掩码、双重访和局部梯度同口径评估。 |
| PC 与 NX 增益一致性 | F56 NX TensorRT 全段报告相对参考最大差约 $2.575×10^{-5}$，阈值 $2×10^{-4}$，非去噪质量误差。 | E ONNX 与 PC 前 3 ping：增益最大 $1.91×10^{-5}$；P32 中前 3 ping PC 与 NX：最大 $3.43×10^{-5}$。均非全部 32/2,020 ping。 |

两者同属小波、原生复回波特征和对数增益设计谱系，但 **不是同一网络缩放、剪枝或量化**。T1 有离线教师哈希用于评估，实际该阶段 `offline_teacher_training_weight=0`，训练代码也按 `teacher_weight=0` 执行；不要把冻结小模型写成由 56M 蒸馏，除非另有前代训练直接证据并严格限定对应阶段。

小模型可追溯的开发值：T3 `evaluations[0].native.weak_verifier_original`（`shift=0`）的已知增噪恢复 log RMSE 为 **0.23952**，身份 log RMS 为 **0.00129**（统计实现 `TrialNativeSpectralHistory172.py:155–165`）。这两项只属于 T3 开发条件，绝不可用来与 V56 的 0.12894 / 0.00739 横向计算差值或质量保留率。
