# 论文创新点一：原生侧扫去条纹与轻量模型部署实验方案

以下是拟开展的实验，不是既有结论。核心问题：相对 56M 大模型，7.52M 因果模型保留多少去噪和几何纹理收益？在真实 NX 上是否能持续处理完整物理 ping？分别论证质量、数值一致性、导航收益和时间可用性。

## 1. 数据划分与公平对照

1. **已知新增干扰**：从独立航次的低干扰实测回波 $z_0$ 构造 $z=z_0+M\eta$，冻结原始对、已知扰动、支持区和 seed。分层选择弧形位置、曲率、强度和未见干扰形态；现有背景不称为“理想干净真值”。若有独立受控干净测量，另立对照。
2. **真实干扰**：保留至少一批未用于训练、模型选择和扰动模板估计的航次，覆盖不同设备、底质、信噪比和视角。训练/验证/测试按航次或物理测线先划分，再生成窗口；避免同航次相邻窗口泄漏。优先采集重访、交叉线或带独立位置参考的航次。
3. **无新增干扰身份测试**：用相同原始观测验证方法是否人为改变弱回波、边缘与阴影。只有同航次资料时，标为重放案例，不称盲测或现场定位真值。
4. **冻结**相同原生 I/Q、噪声实例、有效掩码、校准、初始状态、复位协议、导航权重和同一显示 LUT；各臂不因测试结果调整带宽、亮度或导航阈值。

| 实验臂 | 唯一变化 | 比较意义 |
|---|---|---|
| A 原始数据 | 原始 I/Q 旁路 | 基线 |
| B 传统滤波 | 单独冻结一套可复现传统方法，例如在开发集定参数的 FIR / 方向性频域抑制；说明系数、边界、相位与因果性 | 仅作独立对照，不给模型做前级或监督标签；若使用未来数据，明确为离线 |
| C 轻量网络 | 三权重 W 组装，PC PyTorch 参考、NX J 执行同算法 | 评估质量、时序、平台一致性 |
| D 56M 大模型 | `random_adapted_56M`，同原生输入，离线读取上下文 | 质量参照候选，不默认所有指标都最好，不纳入实时声明 |

## 2. 去噪、纹理和计算成本

- **主指标**：按同有效掩码统计对数幅度 RMSE、线性幅度 NRMSE；按舷、束、干扰强度分层。真实无干净参考不报冒充真值的 PSNR/SSIM。身份集另报 $\mathrm{RMS}(\log A'-\log A)$、增益分位与弱回波保持率。
- **纹理副指标**：在配对地标中报共定位边缘召回、局部梯度相关/幅度变化、真实回波–阴影对比、跨航次特征可重复性。受控集另算条纹空间谱的残能并隔离自然底质形态；区别漏抑条纹与过抑地物。绘图只用相同色表、原生尺寸；排版预览另名，不拉伸。
- **质量—速度取舍**：若 $E_A>E_D$，可报告保留的改进份额 $(E_A-E_C)/(E_A-E_D)$ 及差 $E_C-E_D$ 的置信区间。D 无收益时不解释这个比值。可预注册 ≥90% 的保留目标或基于应用误差容限的非劣界，不按测试集事后选阈值。统计以航次、航段或噪声 seed 为配对单位，用块/航次重采样，不把相邻 ping 当独立样本。
- **复杂度**：两个 R 各按全 16 束、实际形状，报告参数、权重/引擎字节、MACs/FLOPs 定义（乘加 1 MAC 或 2 FLOPs）、56M Halo 重复计算、7.52M 频谱/投影/状态处理成本。理论 FLOPs 不当实测时延。分开量化加载/图捕获、H2D、特征、TensorRT 图及状态、D2H、恢复和导航，另记共享 RAM、进程 RSS、TRT allocator、GPU 利用/频率及功耗。

## 3. 从纹理到匹配和导航

1. 固定 GFTT/RootSIFT 或 LoFTR 的版本、参数和候选池，以独立几何标注或已知变换判定正确匹配；报重复关键点率、precision/recall、RANSAC 内点数量与比例、像素/米制残差、误匹配和空窗比例。P32 的探索性原始/恢复指标并非同向，不能只选残差中位改善。
2. 固定运动流和导航输入时序，四臂比较相对里程计 RPE（多基线）、沿航向/横向/航向误差、配准成功率；按直线、转向、弱纹理和重复纹理分段。已知不可观方向不以插值真值填充。
3. 绝对导航固定相同先验、初始化、运动流、同一噪声；DR 要逐点一致。报 Global 3D RMSE、P95、最大/终点误差、错误约束率和恢复次数；结合全程曲线、配对差与分段失败。若研究地图去噪，先验作为第二个独立因子，做地图/查询交叉实验，不能只对比“好地图＋一种算法”和“差地图＋另一算法”。
4. 现有 H0 同一额外条纹下 Global RMSE 5.441→5.003 m、P95 13.116→11.250 m，H5 RMSE 13.553→11.337 m；R 同航次水平 GNSS 参考差 0.580→0.438 m。见 `A/00_导航对照指标表.csv`。这不是四臂对照，也不证明跨设备现场定位精度。

## 4. 一致性和实时验收

- 固定 W/E/J 的所有工件哈希；同序列对照 PyTorch eager↔graph、PyTorch↔ORT、NX TRT↔PC。在 R12189/12721、冷启动、连续态、复位后分别比较原生 gain、四状态、恢复幅度、保护区 bitwise 恒等。建议报 max/RMSE/P95 和超容差比例；当前 $2×10^{-4}$ 是 P32 的增益门槛，不能挪作导航误差阈值。现有逐样点 NX 证据只包含 P32 前 3 ping。
- 只运行一个生产臂，按真实声呐间隔原生输入。建议目标 5 Hz 时完成不少于 3 次、每次至少 30 min，覆盖热稳态和数据断点；预先约定吞吐不低于输入、无丢包/重排/无界积压、端到端 P99≤200 ms 与超时率目标。报告实际截止期完成率、归档端到端样本与 RAM/温控；不要用 5 Hz 仿真时间轴替代墙钟验收。
- 可选消融：因果骨干、+晚期频谱、+弱回波；同预算同输入下另做去相位或取消同步束共享。比较质量、纹理、匹配和时延，不能因不同训练批次简单归因。
- 交付冻结评测 manifest、受许可的衍生明细或合成 fixture、汇总表与绘图代码；不公开原始 I/Q。数据权限及缺口见 [材料清单](MISSING_MATERIALS.md)。
