## 给网页端 ChatGPT 的审阅要求

请先阅读总览和证据，再修订中文论文中有关侧扫去噪的章节。把三条创新线分开：原生回波恢复与端侧因果推理、侧扫几何匹配导航、可核验同输入的处理器在环。不要将项目历史候选混入实际 7.52M 运行链。参数量用 7,518,563，模型身份和版本沿用审查中的类名、三组训练选择与工件摘要；不要从文件名推导隐藏层精度、构建指令或已达平台实时要求。

写清以下证据边界：

- R12189 是实采接收计划，R12721 是梳形仿真计划。两者是同一架构与冻结权重、不同静态输入长度，不是两套模型。
- 原速度 32 ping 小试运行完成，**只有前 3 ping** 的输出增益与 PC 做逐样点比对，最大差 \(3.43×10^{-5}\)。PC PyTorch↔ONNX 另有独立的 3 ping 数值核对。两个结果不能互换。
- **5 Hz 是补充实验的仿真时基**；模型前向 P99 130.78 ms、板端去噪段 P99 240.00 ms，后者含恢复、不含导航，不能把前者写作 5 Hz 整链达标。持续采样验收仍是拟做实验。
- 大小模型的去噪质量开发集不同；同航次 GNSS 参考差不是独立水下定位真值。传统方法需要独立对照时只放在拟开展的四臂实验中，不写成神经网络前级。
- 明示未入库或未测得内容。不补造精确构建命令、GPU 独占峰值、同口径 FLOPs、独立盲测或精度结果。

这里发布的是审查文档、少量源码摘录和脱敏统计，不含原始声呐数据、原始导航数据、完整权重/ONNX/引擎二进制、未脱敏日志或完整可部署源码包。这些限制不阻止网页端阅读证据，但不构成第三方复现实验发行。
