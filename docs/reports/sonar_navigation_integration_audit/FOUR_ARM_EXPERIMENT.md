# 同一侧扫输入的 2×2 四组实验：预注册方案

**待实验。** R/H0/H5 是当前导航内的旁路／小模型比较，不能填另外两格。历史“不额外加条纹”用于环境分层，不冒充原始导航。

## 1. 钉住两种导航定义

用相同冻结 F 源码，比较已可配置的导航功能包。这是可执行的消融型基线，不声称与某个早期历史提交逐字或数值等价。若另需“按原提交重跑”，先为两版本提供同一包接口并另立实验。

- **N0 原始导航消融基线**：`legacy_strip`、`rank2_baseline`、`canonical_submaps=False`、`mapped_range_changes=False`。
- **N1 改进导航**：`adaptive_projected`、条带仍 `rank2_baseline`、`canonical_submaps=False`、`mapped_range_changes=True`、`mapped_range_policy=preserve_legacy`，与 R/H0/H5 的实际导航开关一致。N1 同时改变转弯表示和重复斜距约束，主试验评估组合；需分别归因时再做“只加投影”“只加 repeated-range”。
- 共同冻结 LoFTR 权重/上下文 mask 开关、GFTT/SIFT、运动滤波、历史回环、共享窗分账、关键帧时钟、确认策略和无效候选防护。开关位置为 `F/standalone/PureSideScanFeatureNavigation.py:58–118,218–245,285–310`；H0 防护见 `HistoricalLoopObservationGuard.py:12–60`。未修改代码实行本方案。

| 组 | 去噪因素 | 导航因素 | 同输入上的实施 |
|---|---|---|---|
| A | 旁路 | N0 | 共同原生 I/Q → 统一接收适配 → N0 |
| B | 7.52M | N0 | 同 I/Q → 固定端上模型 → 统一接收适配 → N0 |
| C | 旁路 | N1 | 与 A **逐包相同**的导航输入 → N1 |

“原始声呐”指同一试验里不开去噪的接收观测；实采含真实噪声，仿真按该批有或无额外条纹。可先用板端实际推理产生两类导航包并冻结，然后重放给四组；同时保留 B/D 真正 Jetson 逐 ping 的端到端实测。缓存服务算法公平性，不能用于在线时延结论。

## 2. 可核验的输入合同

1. 冻结一份公共清单：带噪 I/Q 的序号/时间/摘要、同一参考图/掩码/分辨率、初始位置/姿态/速度/协方差、运动事件、外参、声速/接收时延/范围、gate、模型 plan、LoFTR 和程序依赖。锁定真值、时钟和评分方式。真实测试优先使用独立测线构图与独立位置参考；同航次仅能报告参考偏差。共同运动输入由一份记录或仿真文件给定，不给任何臂使用评分真值恢复位姿。
2. 实采只走幅度接收，仿真两路各做一次相同脉压再用同一包适配。不得为不同导航版本改网格、额外滤波、调 gate、偏移时钟或微调参考图。R 因果状态吃完整物理 ping，不能只让 B 或 D 喂奇数。A=C、B=D 的适配后码流应严格同值。
3. 四臂保持同样冷启动、断点表和连续导航规则；若对照“断点切断特征链”，另做消融。按真采集中断、回环、直线/转弯/弱纹理分层；先短窗 smoke，再做包含转向、重访与 >180 s 可配对间隔的长程。固定相同组的初始化扰动或噪声 seed，跨组只变两个实验因素。
4. 逐包核对时间、舷、束、斜距单位、哈希、回执及 DR 轨迹；保留空包、异常候选、超时和中断，不择取有益航段。相同几何校验若在 N0 开关关闭时不触发，记录为机制差异而非遗漏。

## 3. 主指标、归因及附加检查

令 $E$ 为越低越好的主指标：对齐原时间的 Global 三维 RMSE（仿真）或独立位置参考误差。

- 去噪增益：$E_A-E_B$（N0）、$E_C-E_D$（N1）。
- 导航增益：$E_A-E_C$（旁路）、$E_B-E_D$（去噪）。
- 交互作用：$(E_C-E_D)-(E_A-E_B)$。正值表示在该指标和输入上 N1 能利用更多去噪收益，负值或无显著差异也报告。

同时给出 P50/P95/最大/终点、沿航/横航与短窗 RPE、地图空窗、错误回环与重复斜距因子。按独立航次、路线或 seed 配对，按时间块重采样，不把相邻 ping 当独立样本。另报按舷侧×束×斜距的样点覆盖、关键点和可重复地物、ratio/内点、匹配几何秩与源 token 改变；联系去噪和导航结果，不以点多寡单独评好坏。

- **同支持消融**：锁定共同格，比较纯辐射变化；然后与主试验允许的自然支持变化对照。先在固定关键点上比较描述子，再解冻检测。
- **测距夹具**：用已知标靶/模板峰、两舷镜像和低信噪比回波，比较脉压峰、512 格落点、叠合标签及因子 token；外观变化不是斜距重新标定。
- **单臂时延**：按实际采样速率（若 5 Hz 为 200 ms）分别测接收、特征、模型、恢复、脉压、适配、导航、排队与发布，报告丢包和热稳态。四轨并行 wall time 不代表一轨部署速度。

R、H0、H5 只能提供对应工况的 **C/D**，且各批次不是同一输入、先验或观测机制。A/B、交互项、独立实采位置真值和统一实时验收目前**未做**。
