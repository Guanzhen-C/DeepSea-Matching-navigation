# 论文贡献可写到哪里：与接口证据对齐

本页为论文写作的证据清单，不改原稿、不增加未执行的实验。[第一阶段模型审查](../sonar_denoising_model_audit/README.md)说明去噪模型本身，本页只界定其对导航的实际贡献。

## 1. 可以主张的三条技术贡献

| 贡献 | 可以写成什么 | 支持证据与限制 |
|---|---|---|
| 原生信号级恢复与物理索引接口 | 在原生复数接收格上预测标量对数增益，按实际观测的支持仅改变幅度；设备记录以数值包接口接入，仿真在等效未脉压复基带上恢复后使用同一接收器。明确区分原生格和导航格。 | `RunQiandaoRecordedSmallBoardPilot.serve:238–279`、`RunQiandaoHistoricalClockAB.board:147–169` 与 R/H0 的逐包回执。[输入恢复](DENOISING_INTERFACE.md)。不能声称保护住全部真实弱纹理、恢复了真实无噪相位，或下游达到原生 I/Q 测距分辨率。 |
| 关联与几何分开的纯侧扫导航 | 单 ping 相对更新只使用沿航向可观量；多 ping 条带/投影和 LoFTR 只建立对应，绝对/回环用扫描平面与实际接收斜距几何，重复测距对未知高程做剖面处理；图负责全局校正。 | [导航几何和源码索引](NAVIGATION_INTERFACE.md)。两个仿真批次都有实际回环与重复斜距因子；R 两类因子为 0。不能把已有 LoFTR、iSAM2、GFTT 或 Haar 宣称为原创，也不能用 R 结果单独证明斜距因子有效。 |
| 可审核的实际板端联合验证 | 按相同接收/运动/先验/时钟分流，真实 NX 执行两导航实例，记录引擎回执、去噪改动、几何接受与位置输出；跨越了从图像去噪到导航任务的接口验证。 | [实际流程](END_TO_END_FLOW.md)与[数据一致性](DATA_CONSISTENCY.md)。H0/H5 有共同仿真三维真值；R 为同航次 GNSS 水平参考偏差，不是独立 AUV 水下现场定位；当前无全四组/单臂实时验收。 |

建议在方法章节分别画出**两条接收支路**，标注“实采：直接使用恢复幅度构包”和“仿真：先复 I/Q 恢复、后匹配滤波”，不要合并成同一种匹配滤波顺序。在测量模型章节标明 512 格、束中心、回环/距离来源和压力 z 的角色，避免写“GTSAM 直接接收去噪网络特征”。

## 2. 结果的推荐表述

> 在具有冻结先验图与共用运动流的 Jetson Orin NX 上，我们完成了同一原生接收的旁路/7.52M 因果恢复对照。62,458 ping 的梳形仿真中，全程 Global 三维 RMSE 从 5.441 m 变为 5.003 m；在 103,055 ping 的另一仿真批次中，从 13.553 m 变为 11.337 m。2,020 个实采接收、1,010 个查询的同航次重放中，对 GNSS 的水平参考偏差 RMSE 从 0.580 m 变为 0.438 m。后者未使用独立水下位置真值。前端和末端结果并不总是与全程 Global RMSE 同向变化。

可用[配对统计与问题表](POTENTIAL_ISSUES.md)给出反映任务权衡的证据：P32 中查询特征数减少 33.9%，但这不是正式前端 detector；正式侧扫接受数和地图对应在不同批次分化。不能写“去噪增加有效点数”，也不能写“去噪已证实破坏地物”；数量、误匹配、空间覆盖和几何信息秩要在独立标注上建立证据。

## 3. 还缺什么才能做强结论

- 若要声称“新导航比旧导航好”或“二者组合存在协同”，完成[四臂预注册](FOUR_ARM_EXPERIMENT.md)的 A/B 和共同数据下的 C/D；做回环与重复斜距消融、独立先验和独立参考、转向及弱纹理分层。
- 若要声称“轻量模型逼近 56M 同等导航质量”，用同一配对数据和共同先验完成小/大模型对比，本次只证实 7.52M 对旁路的影响。
- 若要声称“不改变物理测距”，先做可重复标靶峰位、两舷外参和 source-token 保真测试；原生索引不变只能证明没有神经网络重采样。
- 若要声称“实时 5 Hz”或“别人能从 GitHub 独立复现”，分别补单臂完整耗时验收和被允许发布的可运行包／合成夹具；已有遥测和记录可用于复核，不代替重建复跑。既有论文的“32 ping 一致性”应区分 32 次回放与 3 次逐样点核验。
