# 已观察的问题、解释边界和后续核验

## 1. 去噪后点更少：到底少的是哪些点

**已验证：P32 短图像小试中数量确实下降。** 来源 P32 的 `matching`，实现 `RunQiandaoRecordedSmallBoardPilot.feature_report:169–211`。同航次偶数参考（2,083 特征）、奇数查询。两查询用相同有效候选掩码和参考图强度分位，SIFT 检测＋RootSIFT、单向 ratio 0.75、仿射 RANSAC 3 px；不是正式导航的 GFTT＋L2 SIFT 双向 ratio 0.9，也不是 LoFTR。

| P32 查询图量测 | 原始 | 7.52M 恢复 | 解释 |
|---|---:|---:|---|
| 查询关键点 | 2,160 | 1,428 | 减 732（33.9%） |
| 通过 ratio 的匹配数 | 83 | 21 | 减 62（74.7%） |
| RANSAC 内点数 | 17 | 8 | 减 9（52.9%） |
| 内点/ratio 通过数 | 20.5% | 38.1% | 比率升高，但约束更少 |
| 内点像素残差中位 | 0.947 | 0.596 | 只在幸存内点上，不能证明定位准确或只删了伪点 |

**已验证：正式导航的变化不统一。** 从各 `run_summary.diagnostics.{raw,student}.frontend` 读累计计数，这些不是检测关键点总数。定位量采用 R/H0/H5 归档和[一阶段汇总表](../sonar_denoising_model_audit/evidence/navigation_aggregates.csv)。

| 运行 | 前端接受／拒绝／Local 更新：旁路 → 恢复 | 地图接受：旁路 → 恢复 | Global RMSE（m）：旁路 → 恢复 | Local RMSE（m）：旁路 → 恢复 |
|---|---|---|---|---|
| H0 | 62,390／67／20,774 → 62,092／365／20,643 | 384→374（同 416） | 5.441→5.003 | 34.537→34.802 |

同 ping 的 `map_epoch.{accepted,matches,inliers}` 另做配对（各批独立，含匹配拒绝的窗口，按日志默认值处理）：

| 运行 | 两臂均接受／仅旁路／仅恢复／均拒绝 | 地图匹配数中位（旁路→恢复） | 地图几何内点数中位（旁路→恢复） |
|---|---|---|---|

R 的 838 对“双臂前端均接受”查询，正式前端匹配数中位 38→41，逐对差中位 +3；不外推至被拒窗口。LoFTR 的 `query_feature_count` 多为筛选后对应数，不能和检测关键点数合并。H0 终点 Global 4.503→4.894 m、H5 终点 12.056→23.233 m（表 `final_m`）；全程 RMSE 改善不表示每个航段或终点改善。

**解释**：去噪改变了能进入匹配的外观和约束集合，但既不能归咎于有效弱特征被删，也不能全部归功于去掉伪条纹。若余下特征集中在单舷或有限范围，几何也可能退化。需用独立重访地标追踪真实纹理存活和空间覆盖。

## 2. 逐项核查

| 问题 | 已知机制／证据 | 待量化影响与验收 |
|---|---|---|
| 弱特征过抑制 | `NativeWeakEchoVerifier.py:10–31` 限制对父增益的缩放，不能保证弱回波、阴影边缘或检测响应不变。小试数量变化是真观察，少的是否有效地物仍不清楚。 | 标注跨测线可重复地物及人工条纹；按弱回波强度区间量化生存/误抑、重复性；先固定检测点比较描述子，再解冻检测。 |
| 空间分布与相位中心选择 | `PureSideScanFeatures.py:88–151` 的归一化/插值/角点会重排响应；`SideScanFeatureMap.py:134–147`、`SideScanProjectedSubmap.py:84–102` 按幅度选主来源，去噪可改变同栅格对应的束或 ping。日志只有总数及少量例图，不具备全程分布坐标。 | 按舷、束、斜距、扫描方向报告覆盖/几何奇异谱和来源标签改变率；逐层保留原生、适配、特征和几何。不能从总数证明具体哪侧减少。 |
| 左右舷一致性 | 顺序固定、权重共享，两舷独立 8 束状态，适配代码同一套；R 门是分舷广播，H 分舷分束估计。本次复算 R 两个 gate 各 24,621,780 值，与同批原支持数组对应舷逐值相同；$w>0.5$ 左／右占 78.349%／78.257%。这是覆盖差异，不是侧别精度。 | 用两舷交换的校准夹具和同角度/同距离标靶按束比较，不把镜像外观翻转误作板端重排；尚无单舷测距或定位偏差验收。 |
| 斜距对应 | gain 不改变原生索引 $k$；接收聚合到 512 格，后端使用接收格中心或条带子像素斜距，具体见 `SideScanIQHistory.py:79–88`、`SideScanMappedRangeBank.py:18–41`。增强改变能量与主贡献，仿真还可能改变匹配滤波后的峰。H0 已拒绝非正等坏观测。 | 实测已知反射的脉压峰、范围格和 token 跳变；不可宣称“原生索引不变所以测距和匹配误差不变”。 |
| 断点与导航分段 | R 有 25 次去噪初始化/重置（含开头）：`AuditRecordedSonarContinuity.py:21–38` 按原 ping 编号、源记录单元、时间异常及文件边界；`QiandaoRecordedInputs.py:36–47`、`RecordedTrack.expect_reset:46–47`、`serve:238–253` 重建特征缓冲和引擎状态。**导航实例没有同步重建**，其前帧/滑窗/图按实际时间及运动代理跨断点（`RecordedTrack.add_received:49–78`）。H0/H5 连续仿真，开头后无这类重置。 | 将同原始记录 V7 的复位表与 R 的奇编号索引对齐，六个完整 150 查询窗内部断点数为 0/4/4/5/4/6（索引复核；R 回执只给总重置数）。应另做跨缝继续 vs 只清前端链/子图的消融，不能由断点数认定位置误差原因。 |
| 预处理时延 | H5 模型 P99 130.78 ms，含 gate/前处理/推理/回收/复回波恢复的 `denoise_ms` P99 240.00 ms，不计后续脉压/适配/导航（`RunQiandaoNoisyCombBoardAB.py:96–111`）。R `full_denoise_ms` P99 330.54 ms **止于** `stream.run`，幅度恢复、512 格和导航在其外（`RunQiandaoRecordedSmallBoardPilot.py:250–277`）。H0 只记录模型 P99 132.85 ms。 | 这些不是同口径全链时延；补 gate、脉压、栅格、每 150 ping 的 LoFTR/图长尾及队列，把单臂时延与双臂回放吞吐分开。 |
