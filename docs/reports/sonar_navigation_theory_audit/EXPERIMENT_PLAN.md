# 补充实验：从几何到独立航次

**以下是待执行设计，不是已有结果。** 既有 preserve_legacy 对照和板端触发记录见[实现审查](IMPLEMENTATION_REVIEW.md)。本阶段固定去噪臂（原则上以原始输入为主，另一臂另行复验）；不要用改变去噪或投影算法的结果归因于斜距项。二阶段去噪×导航四臂将作为外层实验，[见阶段二协议](../sonar_navigation_integration_audit/FOUR_ARM_EXPERIMENT.md)。

## 1. 三层执行顺序

1. **受控几何／Monte Carlo**：生成 3D 静止散射物、逐 ping 相位中心、航线与合成原距，标记真实对应。直接运行现有因子和对照，分别在真值/扰动位姿测死区、边界、局部秩与误关联。对比映射区间端点及一维全原距代价的数值最小值；不要把两者相等当断言。
2. **冻结关联图重放**：冻结 odometry、绝对地图先验、候选回环、斜距配对、每个因子权重、初始化、锚点、时间戳和评价真值；从相同保存流按预定义掩码关闭约束，不重新做关联。记录 hash、关开的精确因子数量、在线与全历史结果。这样测“边本身的作用”。如果历史流无法恢复某组边，先补采可审计因子流；不重造缺失数据。
3. **闭环导航与独立航次**：复跑四个图配置，允许状态变化影响关联，单独报告“系统总效应”。至少另有不同地形/设备日/独立路线和独立测绘地图；真实水下真值优先用独立验证的声学定位或测量网，并报告精度、时间对齐和参考框架，不能用导航自己的 Local、同一侧扫镶嵌的定位或插值轨迹代替真值。板端复跑只用已核实运行链路，在确有因子激活的片段测延迟与增益。

## 2. 十类试验及验证对象

表中数值是预设水平，可由标定再冻结。每次保持非目标变量相同；先做单因子扫描，再做少量交互（$\Delta z$×噪声、航向×重叠、关联错误×鲁棒核），不必全积。

| 试验 | 控制变量与水平示例 | 必验输出 |
|---|---|---|
| 1. 海底起伏 | 平坦／平缓起伏／局部陡坡；保存相同水平散射体分布，记录地形 RMS、坡度及纹理；固定量程与相对航高分层 | 可见性/阴影、真实匹配率、死区占比、误差，分清地物高度与载体高度 |
| 2. 航向夹角 | 0/15/45/90/135/180°；在数据生成时分别控制重复区域覆盖与水平基线方向/长度，不从夹角直接推断满秩 | 横/沿航向与航向信息、同方位样本的秩、跨视角匹配成功率 |
| 3. 垂向高度变化 | 0、$10^{-6}$、±0.05、±0.25、±2、±12 m；再注入共同基准偏差、差分噪声、姿态依赖杆臂 | 活跃率、死区宽度、单边差分、差分误差导致的虚假外域修正 |
| 4. 斜距噪声 | 0/0.1/0.7/1.5 m，另测同 ping 相关、声速比例和零时延误差 | 未截断原始创新校准、不同分支偏差、覆盖率 |
| 5. 地图位置误差 | 独立随机 0/0.5/2.5/5 m；共同平移、航向扭曲、空间相关偏移分开注入 | 比较节点基线与真实接收基线的方差估计；分析系统偏差与覆盖率 |
| 6. 误关联 | 0/5/15/30%；区分同窗近邻误配、重纹理成团及错误舷侧 | 错配逃过死区比例、外域影响、Bank 拒绝精度和地物级召回 |
| 7. 单次与多次 | 同地物 m=1/2/3/5；已知近时共噪声、跨线不同方位两组 | 比无斜距边、现有不复用成对、以及共高程变量联合原距/联合差分；禁止把重复行算新信息 |
| 8. 未知高度剖面 | 只开原有因子基线 vs 加现有区间因子；另加能使用两原距的有界联合剖面、固定真高度 oracle、必要时固定平面高程基线 | 不以 oracle 作公平主对照；覆盖退化、物理可行拒绝、收敛域、运行效率。不同高度却把 $Z$ 任意设 0 只可算错误模型诊断 |
| 9. 预算与鲁棒核 | 重复边按现有预算／不做预算降权，有／无伪 Huber，做 2×2；legacy 地图/回环精度固定。再对 $\beta$ 和有效行数上限做灵敏度分析，不事后选最佳航次 | 截断前后方差、置信覆盖、错配破坏率、改善是否来自过度加权 |
| 10. 斜距与回环消融 | 同一绝对地图和里程计下，斜距×历史回环均关、仅斜距、仅回环、二者开启；静态图冻结既有权重，在线另报共享预算默认策略 | 两项主效应及交互、见到重复来源时的解释、失败段与跨航线恢复 |

第 8 项联合原距对照可最小化 $\sum_i (r_i-\sqrt{\|v_i\|^2+(Z-z_i)^2})^2/\sigma_i^2$，有界求一个共同 $Z$，或在图中保留同一个 $Z$ 后消元；使用联合协方差时改为二次型。用可行交集和有限噪声模型处理不相容数据；不要为了“证明现方案更好”给对照不正确的区间或劣化的初始化。另可做严格物理一致性检查（[反例](MATHEMATICAL_MODEL.md)），将其作为独立模块消融。

## 3. 样本、主指标、验收

- 预先冻结地图、程序和数据哈希、噪声与关联种子、可复现仿真配置、杆臂标定、频率/量程/子图窗口、大横向偏移工况和目标干扰；保存每条边两端、两次 token、受理/拒绝原因、分段活动状态、协方差或近似、优化时间。冻结每个单位的真值来源及有效时窗。
- 受控单元测试断言正确分支与雅可比；平滑点测试世界和局部切空间，角点走单边；在不同尺度扫有限差分步长（建议 $10^{-4},10^{-5},10^{-6},10^{-7}$），再检查线性化外推、位姿初值偏差和长期恢复。专门检查非有限输入、错误量程、竖向高度重置、跨航次 token 冲突、旁路去噪对应一致。
- 对每臂主报 Global 水平 RMSE、沿/横向 RMSE、100 m/500 m 尺度相对误差、P95/峰值/末端误差、跟踪失败与恢复时间，辅报航向、覆盖率、每航线有效行与特征轨迹、原尺图像关联以便追溯。参数标定用独立训练或开发航次；至少先用不少于 30 个合成种子估计变异，再据先导方差确定外场样本量。以航线/航次为成组单位给配对区间，不能把每个 ping 当独立显著性样本。
- 在实验前冻结实际有意义的最小改善值和允许的失败率，而非看到曲线后设指标。结论至少要求：数学单测通过；可辨识方向改善且退化中无系统性劣化；冻结图和在线结果各自可复现；独立外场报告差异与不确定区间。如果独立边贡献小或仅在特定航线出现，论文就限定作用域，不承诺普适提升。
