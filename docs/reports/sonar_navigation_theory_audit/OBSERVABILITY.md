# 几何与局部可观性

这里审计的是几何行在确定工作点的一阶可观性，不等于完整 SLAM 的可观测性，也不是某航次的实测定位精度。有关实现见[重复斜距行](../../../standalone/SideScanMappedRangeChange.py#L101)、[历史回环的距离和扫掠平面](../../../standalone/SideScanLoopGeometry.py#L25)、[回环的纯数据 Schur 信息](../../../standalone/SideScanLoopGeometry.py#L52)。

## 1. 一次观测与多时刻原始模型

设原距预测 $\rho_i=\sqrt{\|v_i\|^2+(Z-z_i)^2}$。线性化单行的位姿扰动为 $-v_i^\top(dt_i+d_i\,d\psi_i)/\rho_i$，高度列为 $b_i=(Z-z_i)/\rho_i$。一次距离对应球面，若另知道扫掠平面则进一步限制到圆弧，再用舷侧和下视分支消歧；这些不是重复斜距行的额外观测。若 $L$ 已给定、$Z$ 无先验且在可行区内部，单距离且 $b_i\ne0$ 时，可用高度扰动吸收任意一阶投影，边际位姿信息为零。高度边界或 $b_i=0$ 是例外，须分开分析。

给原距位姿雅可比 $A$、高度列 $b$ 和真白化权重 $W$，局部消元后的信息为

$$H_{\rm red}=A^\top W A-A^\top Wb(b^\top Wb)^\dagger b^\top W A.$$

这也给出了更完整的对照：同一地物连续 $m$ 次原距，在一般非零高度列下剖面信息最多 $m-1$ 个独立标量方向；若先对平方距离相同参考做 $m-1$ 次差分，再剖面未知 $Z$，垂向变化使差分高度列非零时最多 $m-2$ 个，全部等高则最多 $m-1$ 个。以上都是秩上界；量测相关性、方位重合或其它退化会进一步降低有效秩。当前实现不是上述联合模型：只对选出的不重用 token 对各做区间剖面，不为同一地物跨边维持一个共享 $Z$，也未白化共享轨迹和地图误差。

## 2. 当前图中，什么时候能限制横向、沿航向或航向

- 先固定 $a$，只看 $b$。激活行的平移方向为 $v_b^\top$；所有特征同方位时平移秩至多 1，至少两个非平行向量才可能有平移秩 2。近侧向观测，以沿航向为 $x$ 时，常见的是 $|v_y|\gg |v_x|$；于是横向强，沿航向弱。码中的采样间距和数量并不改变这一几何事实。
- $u_b=0$ 时航向列为零。若所有行共用一个水平杆臂 $u_b$，偏航列由平移列线性组合，仍无法独立区分平移和偏航。不同 ping/通道带来的实际水平偏移、不同方位及被激活的有效行共同满足秩条件，才可能在单锚点下达到 Pose2 秩 3。
- 两节点均自由时，一个地物至多一行；不能把它当作完整相对 Pose2 测量。每个时刻的接收原点若均固定不变，平移块按 $L$ 线性加常量，平移秩至多 3；若两原点还重合，则至多 2。对固定地图只共同平移两个载体，$J_{D,t_a}+J_{D,t_b}=2(o_b-o_a)^\top$。所以它一般不是对两个位姿共同平移不变的纯相对边；共同变换地图与载体时才有几何坐标系不变性。
- 平行、交叉、反向航线会改变重叠、真实散射重复性、扫掠平面及 $v_i$ 的方向。没有一个航向夹角必然满秩；180° 反向仍可能只有狭窄方位覆盖，90° 在海床纹理随视角显著变化时也可能关联失败。扫掠平面约束能增强回环几何，但不能算入本因子贡献。
- 外域行激活提供向可行域的修正，不表示真值附近有局部 Jacobian。两次估计接收高度不等且真值对应的高度在允许区间严格内部时，所有这类行都会消失；必须同时报告活跃比例、最小奇异值和垂向工况。不能拿死区内的零残差当作高置信定位。

## 3. 怎么数值确认

先固定源节点，在同一量纲尺度下对实际激活的雅可比叠栈做 SVD（把偏航 rad 用明确的参考杆臂转成相同尺度）；再在全图锚定约定下比较关/开斜距边后的低特征值与方向。报告数据行、先验行、回环行三者的秩贡献，不把 LM 阻尼当作真实信息。合成秩例和边界数值检查见[实现审查](IMPLEMENTATION_REVIEW.md)。作为参考，[历史回环的实现](../../../standalone/SideScanLoopGeometry.py#L52)确实有 3D 地物 Schur 消元，但不能把其 $3\times3$ 相对位姿信息矩阵作为本因子的可观性证明。
