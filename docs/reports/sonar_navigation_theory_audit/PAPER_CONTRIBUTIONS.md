# 论文贡献边界与相关工作

**判断：有条件成为独立的导航算法贡献，但凭现有证据不宜宣布已经成立。** 可主张的是特定测量如何成为地图辅助导航的图因子，以及它在哪些航线和垂向条件下提供额外信息；不应把两次平方距离相减本身称为原创，也不能以整套去噪 HIL 指标替代因子独立验证。

## 1. 可辩护的技术表述

> 面向只有水平地理参考、无逐地物测深的侧扫强度图，本文从跨窗重复观测中恢复带 ping/通道/距离列来源的两条斜距。以固定地图 XY 和两接收时刻垂向估计为条件，在物理尺度给定的高度包络内闭式剖面平方斜距差，将剩余一致性约束直接加到两个变量位姿上。分析其等深约束、非等深死区、局部可观方向与噪声相关性，并单独评估它相对于图像地图匹配和传统历史回环的增量。

末句的“单独评估”在完成[补充实验](EXPERIMENT_PLAN.md)后才可用于定稿；现阶段应写“已有三组仿真消融作为初步证据，尚欠完整统计与外场独立验证”。源码：[闭式剖面](../../../standalone/SideScanMappedRangeChange.py#L93)、[来源/时间不重叠配对](../../../standalone/SideScanMappedRangeBank.py#L66)、[双位姿因子](../../../standalone/SideScanMappedRangeGraph.py#L35)。不把算法依赖的固定地图写成“完全无地图”，不把固定垂向估计写成“不需要深度信息”。

## 2. 已有方法与本工作的实质区别

| 一手文献 | 已做的内容 | 与本项目的区别及论文口径 |
|---|---|---|
| [Norman 与 Mangelson，OCEANS 2026 作者公开稿，§IV 式 (3)–(6)](https://arxiv.org/html/2609.25271v1#S4) | 已用两个侧扫斜距的平方方程相消得到线性平面；已知相对位姿，保留球面并结合视场分析未知 3D 地物的位置歧义 | 平方差共享基本数学。本项目反过来，取已匹配地图 XY，把载体位姿当未知；用高度区间剖面差分并直接加图。不应把对方关于 3D 重建的最优夹角直接套给本方法的定位 |
| [Zhang 等，IEEE JOE，同行评审版本 DOI](https://doi.org/10.1109/JOE.2024.3503663) · [作者全文 §III-C](https://arxiv.org/html/2312.13802v2#S3.SS3) | 重叠侧扫子帧稠密对应，由各帧的斜距和扫掠平面拟合 3D 地物及相对位姿，随后作位姿图约束 | 与本项目历史回环思想直接相关。重复斜距因子不同：固定地图 XY、不同垂向时取有界差分残差、不形成独立的相对位姿测量。应实现公平的全原距/距离+平面对照 |
| [Davenport、Jang 与 Meyer，2023 作者稿](https://arxiv.org/abs/2306.06822) | 提取侧扫地标斜距，在序贯贝叶斯框架中约束位置和航高 | 不声称“首次将侧扫斜距用于导航”。可比较有无地物完整几何、直接距离似然与差分区间因子的取舍 |
| [GTSAM 官方教程，第 3、7 节](https://gtsam.org/tutorials/intro.html) | 通用因子图、自定义因子及增量求解 | 本项目贡献是声学残差与接入策略，非 GTSAM/iSAM2 或通用图优化本身 |

GFTT、SIFT、LoFTR、伪 Huber 和通用变量剖面/消元也是已有方法；只归因于自己的观测建模、配对约束与系统集成。上述文献比较不是穷尽优先权检索，不能据此作“全球首创”的排他判断。若将 HIL 或去噪作为另外贡献，应分别引用自己的证据，并避免用整套系统效果重复证明同一项。

## 3. 还缺哪些证据

1. **几何与概率：** 给出差分松弛和完整原距剖面在何时近似等价、为何丢掉公共模态；建立高度/斜距误差及地图/回环共享信息模型，或提供在明确条件下可校准的近似；解释为何近等深也可能一阶无信息，报告条件数和可观方向。
2. **独立因子收益：** 固定关联的图重放和闭环导航都做“斜距×回环”四组；用两原距联合高度参照和不加斜距基线，保留现有历史航次的负例与末端劣化。真实观测中没有实际触发因子的航次不能证明因子收益。
3. **独立外场与系统效益：** 独立测绘地图和独立真值，包含等深、明显变深、相反/交叉航线和重复纹理；给出噪声/错配下的失败模式和置信覆盖率。若主张更轻量，还需给出联合高度对照下的 CPU/板端增量时延、关联数量及资源，而不是引用整网去噪吞吐。

如果主要收益来自特定几何且统计边界容易说明，可把贡献限定为**侧扫强度图导航的跨窗补充约束**。如果独立消融未显示稳健收益，保留为系统方法的一部分更合适，不必硬拆成单独的高水平算法贡献。
