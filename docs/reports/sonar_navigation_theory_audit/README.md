# 第三阶段研究审查：未知地物高度下的侧扫斜距变化约束

**结论：核心差分模型及解析雅可比正确，但它只检查“两条斜距的平方差”是否与某个允许高度相容，并不检查两条原始斜距能否由同一个物理点同时产生。** 接收器不等高时，正确匹配在真值处也可能落在死区，局部一阶信息为零。斜距因子可作为论文的候选独立贡献，现有材料不足以主张“新的双视角声学几何”或“统计一致且普适改善”。

## 2. 论文应强调什么

可强调的是：**无逐地物高程的侧扫强度图上，利用跨窗口重复接收斜距构建双位姿的有界高度因子，及其有效条件。** 不可把平方差几何、GFTT/SIFT/LoFTR 或 GTSAM 自身归为原创。独立贡献成立前，优先补“固定关联的斜距×回环消融、原距联合高度剖面对照、独立地图和真值的外场验证”，同时审计垂向差分与共用观测对置信度的影响。见[相关工作与论文表述](PAPER_CONTRIBUTIONS.md)。
