# 公平对照和逐阶段准入计划

## 阶段 A：本轮已做

- [执行器](../../../research/sonar_range_factor_v2/experiment.py)生成共享地图、声学原距、每 ping 杆臂偏移、接收器高度、航向、正负舷、先验及摘要；使用相同地图和观测比较无距离、M0、M0 无鲁棒/无降权、M1、M2。M1/M0 只组成不相交的观测对，M2 使用这些相同原距合成一个轨迹，不添加额外观测。试验条件用水平和随机种子记录。
- 运行高差、航向夹角、地形起伏、噪声、错误关联比例、地图误差、重复观测数、横向基线扫描及耗时。主扫固定航向估共用二维漂移，地形起伏改变真实高度但未模拟外观、多径、波束视场或遮挡；单因素扫描不用于推断所有交互。地图协方差做单独灵敏度，不调标准差来选择最好动图。全测试和结果见[证据](MONTE_CARLO_RESULTS.md)。
- 用冻结历史回环的真实几何求解器（已给定合成关联），比较无边、历史回环、距离和两者结合。单景演示有观测重叠，不构成完整导航或独立信息增益。非光滑、物理失败和误关联都单列，不把失败静默过滤出结论。

## 阶段 B：待做，固定关联重放

1. 只读使用历史因子流及原始回执，通过 [M0 存储](../../../standalone/SideScanMappedRangeGraph.py#L72) 读取旧配对、距离、原点偏移、高度、节点及配置，通过 [Bank trace](../../../standalone/SideScanMappedRangeBank.py#L127) 链接来源。冻结地图/时钟/运动／初值／回环／绝对先验／图时间轴/真值，以哈希校验。发布只允许含授权的去标识衍生物。
2. M0–M1 优先在严格相同两臂配对上重放，禁止用新模型重选数据。若旧输出仅有每对平均地图 XY，不能靠近似合并把它当共享地物身份。M2 要额外取得固定 track ID、每原始观测的地图对应和跨窗同地物证据；不够时仅比较 $m=2$ 的等价性，标注 $m>2$ 尚不可复跑。截止碰到一个点多列、多 ping、地图匹配再利用等，应保持共源标识。
3. 对 M0/M1/M2 分别三种固定背景（无回环、历史回环、回环+该距离）及无距离的两套基线；地图先验/里程计全程相同，既有历史回环权重不随模型改变。另加三条对照：显式排他 vs 重叠白化，传统高斯 vs 各模型等价尺度的稳健估计，视角/杆臂偏差下的外点分层。对合成的重复数比较优先改用同航线序列的嵌套子集（同一前两视图），验证推断的边际增益。
4. 输出对齐逐样本 Global 平面 ATE/RMSE、P95、末端、方向和峰值，相同真值区间；局部斜距一致性、真错关联、秩、分支切换、病态及回退；活动窗/全图时延、内存、累计填充计数。与本轮 2D 小图 CPU 耗时分开。

## 阶段 C：待做，闭环导航和独立外场

固定版本、去噪臂、接收器标定和全部输入，允许导航回传影响关联，分开报告闭环系统效果与固定图效果。用独立生成先验图与定位真值，在多航次覆盖等高、较大高差、重复纹理、平坦/斜坡及 0–180° 典型航向；至少一个区域和航次完全不参与调参。校准噪声及门控；成对记录 GTSAM/板端恢复和失败工况，明确数据显著相关。做去噪×导航四臂时不得同时换地图或位姿流，[第二阶段协议](../sonar_navigation_integration_audit/FOUR_ARM_EXPERIMENT.md)仍有效。

准入：数学、有限差分、受控等价、非光滑/错误输入可诊断已经做；在固定重放、独立真值、统计覆盖、最坏超时/掉线表现达到预先确定的应用阈值前，不改正式算法，也不把合成收益写成 HIL 或外场收益。
