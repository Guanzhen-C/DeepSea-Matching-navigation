# M0：冻结的平方斜距差分因子

以第三阶段审查为基线，正式的 [Change](../../../standalone/SideScanMappedRangeChange.py#L93)、[Bank](../../../standalone/SideScanMappedRangeBank.py#L66)、[Graph](../../../standalone/SideScanMappedRangeGraph.py#L35) 和历史结果不做修改。合成比较直接导入原残差函数，并校验 Change 的 SHA-256；不复刻一个简化模型冒充正式 M0。详细推导见[第三阶段数学模型](../sonar_navigation_theory_audit/MATHEMATICAL_MODEL.md)。

设米制水平距离 $d_i=\|L-o_i\|$。M0 保留

$$D=d_b^2-d_a^2-r_b^2+r_a^2=2(z_b-z_a)(Z-(z_a+z_b)/2).$$

对包络中的高度作截断后，残差 $q=D-\operatorname{clip}(D,\ell,h)$，再除以 $(r_a+r_b)\sigma$ 并使用伪 Huber 和行预算。它消除了公共平方距离模态；等深时对真值保留一个一般性约束，不等深时真值往往位于严格内部，局部梯度和曲率均为零。这不是相同图的二次/一阶实现错误，而是采用差分松弛的直接结果。

- **值得保留。** 计算为逐行定长代数、来源和轨迹性能已有审计、无迭代地物高度变量、适合做旧导航回归和论文对照。缺失相位中心/声速精标时，它丢掉的共享方向有时也正是系统误差最大的方向；不能先验保证 M1/M2 总更准。
- **比较输入。** 合成中 M0、M1、M2 读相同地图 XY、相同声学距离、同姿态先验和尺度、同候选，不公平的真值过滤不参与优化。M0 保留正式残差默认高度包络、鲁棒核及 0.5 预算；额外报告 M0_plain（同一代数，关闭伪 Huber、预算为 1）。距离尺度使用合成生成器的 σ（无噪声条件用公开的 0.05 m 求解下限），地图标准差同生成配置，相位中心噪声在定位扫描中未注入。M1/M2 主扫用原始距离的高斯代价，不伪装为同一损失；另设失配条件并保留负例。脚本执行的是几何约束对照，**不是**重跑因果 Bank 或整个正式图。
- **区间区别。** 合成三个模型用同一量程 250 m 和相同接收器高度；M0 只能走冻结的宽包络，M1/M2 用明确的同一下视交集。比较以模型完整机制为主，而非只隔离差分表达式；第三阶段已证明 M0 非等高严格内部死区和零差分反例，不依赖以不同区间偏袒新模型。后续可追加同包络的研究对照，但不能改正式函数。

M0 与 M1 的特殊局部关系：若两中心等高且同一地物的真实垂距不为零，两原距线性化时，高度影响方向 $b_i=(Z-z)/\rho_i$；差分向量 $[2r_a,-2r_b]$ 在真值处与该方向正交。因此在相同协方差正确归一且关掉截断/鲁棒/预算差异时，二者保留同一一阶信息方向。优势主要比较非等高、原距物理相容性、相关噪声和边界，不是重新发明等深差分。
