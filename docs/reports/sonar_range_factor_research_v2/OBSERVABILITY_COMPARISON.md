# M0/M1/M2 的可观性与共享信息

在正确关联、光滑内部工作点和白化矩阵固定时，用 [联合 Jacobian](JACOBIAN_AND_OPTIMIZATION.md) 消去一个地物高度，可做局部结构比较：

| 模型 | 每地物可用的局部行 | 退化及条件 |
|---|---|---|
| M0 | 每对最多一行；等深是正常等式；非等深且严格区间内部为零 | 即便差分残差零，不能证明原距物理可行；在外侧可提供拉向区间的修正 |
| M1 | 两个原距减去一维高度 nuisance；一般至多一行内点水平信息；稳定活跃端点则取固定高度的两行秩 | 等深正确模型下一阶与合理白化的 M0 同方向；非等深不再有整个高度区间引起的死区，但不保证满秩；地物近天底、同方位或投影后两行相消仍可退化 |
| M2 | $m$ 次同地物，独立的一维高度方向投影后最多 $m-1$ 个方向 | 高度匹配真且跨视角几何提供方向才有额外有效信息；共误差或同轨迹重复可使有效秩远小于计数，错误合并会系统偏置 |

**信息增益何时成立。** 在相同线性化点、同一波束/地图/姿态、同一整体正定协方差下，记 $B_{\rm pair}$ 为每个非交叠观测对有一个自由高度时的白化高度列，$B_{\rm share}=B_{\rm pair}{\bf 1}$。$\operatorname{col}(B_{\rm share})\subseteq\operatorname{col}(B_{\rm pair})$，故 $P_{\perp,\rm share}-P_{\perp,\rm pair}\succeq0$，乘 $J_p^\top$ 与 $J_p$ 后仍半正定。信息严格增加须 $J_p$ 确实投到新增子空间；同一个地物的两个观测时无增量。这个比较针对联合 Schur，不适用于不同鲁棒权重、边界、错误身份或在分别独立白化时忽略了跨对关联。

**航线、杆臂和垂向。** 目标的水平信息来自 $-v_i^\top G_i/\rho_i$，对窄角足迹常横向强、沿程弱；多方位可改善降秩但与数据匹配成败耦合，不能用 90° 或 180° 直接宣称可观。杆臂 $u_i=0$ 时该次观测不直接提供偏航；同一固定杆臂的偏航列可落在平移列空间。本文的定位扫描固定各次航向，只观测在重复航线中的共同二维漂移，因此航向角扫描不是航向估计精度测试。近等高没有 M0 的那种死区，并不允许将深度误差忽略：当 $B$ 小或几何相近，消元变得敏感，需报告奇异值、间距和病态条件。精确边界可用的高度约束不是外场中的独立测深。

**证据边界。** [单测](../../../tests/test_sonar_range_factor_research_v2.py)在合成四视图轨迹上验证了 Schur/显式数值解、1/3 个高度投影后的行方向；[扫描结果](MONTE_CARLO_RESULTS.md)给误差和失败。尚无真实独立地图和逐地物标签支持“更多观测一定带来更准定位”。
