# 论文第二创新点：可主张到哪里

## 推荐论文技术路线

将 **M1 作为主方法、M0 作为已验证基线、M2 作为可选多视角扩展**。M1 是相对 M0 有可证明物理改进且不增加图状态的最小改动：不依赖已知逐地物海床高度，保留原距共模相容性；有界剖面明确区分内部、固定端点和真正切换；可在光滑区直接接双 Pose2 GTSAM 因子。M2 的同一地物轨迹对问题另有价值，但身份错误会扩散到所有视图；应先可信重识别及处理相关，再讨论将其作为主算法。

建议贡献表述：

> 针对只具有水平地理参考、缺少测深真值的侧扫强度图导航，构建以原始声学距离为基础的下视有界高度联合约束。对两次接收，刻画其剖面最优解、边界切换与相对于平方距离差分的局部信息，并给出双位姿因子的可实现形式；对多次重复观测，定量分析共享同一高度相对独立配对的可观方向、增益条件及关联敏感性。

“带标定的统计一致性”“独立外场中稳定提高”只可在对应实测通过后写。本文不主张包络定理、Schur 消元、一般变量剖面、GFTT/SIFT/LoFTR、GTSAM 是创新。

## 相关工作边界

- [Zhang 等，IEEE JOE 作者公开稿 §III-C](https://arxiv.org/html/2312.13802v2#S3.SS3)，[同行评审 DOI](https://doi.org/10.1109/JOE.2024.3503663)：已经用两次或多次侧扫原距、扫掠平面与未知三维地物参与局部拟合。这里的区分是**固定已知/给定的地图 XY、只剖面下视高度、直接约束两个全局图节点**，不是“首次联合原距”，M2 同样不能仅凭使用共享地物称原创。
- [Norman 与 Mangelson，OCEANS 作者稿 §IV](https://arxiv.org/html/2609.25271v1#S4)：已描述两侧扫平方距离间的线性平面与球面约束；本研究关注位姿估计、无需地物高度输入的有界且带噪目标，不能把平方相减或两次原距本身称新。
- [Milgrom 与 Segal，Econometrica](https://web.stanford.edu/~milgrom/publishedarticles/Envelope%20Theorems.pdf) 与 [Golub–Pereyra，SIAM](https://doi.org/10.1137/0710036) 提供通用剖面灵敏度与变量消元数学背景；本模型是具有非线性 nuisance 和活动边界的具体应用，不能假定线性可分变量的投影自动等价。

## 理论和投稿判断

**有形成独立论文贡献的潜力，但当前不足以确认独立的理论创新。** 可区分的内容是按实际下视硬件模型推得的全局候选、由原始双距保证的零代价物理相容性、切换处不伪造导数以及等高与非等高信息差异。到高水平投稿仍至少需要：相关噪声的可识别模型及实际标定；真实源数据与底图的独立性／外点模型；完整固定关联与原有回环的公平消融；不同条件下的外场与运行时间。若最终仅有普通的联合最小二乘且没有可证明或可重复的增量，应作为系统改进贡献，避免夸大理论新意。

需要取得的资料：带完整 IQ/脉压/时钟/通道元数据的多高差侧扫航次，已知标靶位置和高度，独立地图及定位真值，压力/声速剖面/三轴安装标定，跨航线人工验证的物理 track 数，未参与标定和选型的独立湖海验证，闭环故障/耗时/内存日志。详见[标定方案](STATISTICAL_CONSISTENCY.md)与[实验协议](EXPERIMENT_PLAN.md)。
