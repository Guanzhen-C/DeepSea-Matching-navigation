# 原距物理可行性：严格判别与带噪使用边界

给定候选地图 $L$、当前相位中心 $(o_i,z_i)$、距离 $r_i>0$ 和被允许的下视区间 $I\subset(-\infty,\min z_i]$，令

$$\eta_i=r_i^2-\|L-o_i\|^2.$$

**已证明。** 无噪声时，任一 $\eta_i<0$ 即不可能（量程小于水平距离）；否则只取下视根 $Z_i=z_i-\sqrt{\eta_i}$。所有根相同且公共值属于 $I$，是原距离模型存在同一个物理解的充分必要条件。若使用真实收发分置、多路径和声线折射，必须更换几何模型；若允许散射点高于传感器，必须另做带根符号的组合判别，而不是用本公式单支强判。

对每条距离容差 $\epsilon_i$，测距允许带 $[\max(0,r_i-\epsilon_i),r_i+\epsilon_i]$。扣除 $d_i^2$ 后，若上界为负则无解；否则因 $\rho_i(Z)$ 在下视支单调不增，反像区间为

$$[z_i-\sqrt{(r_i+\epsilon_i)^2-d_i^2},\ z_i-\sqrt{\max((\max(0,r_i-\epsilon_i))^2-d_i^2,0)}].$$

所有反像与 $I$ 的交非空即通过。代码记录 $\eta$、根和交集，默认 $10^{-9}$ m 仅处理浮点；合成研究用公开的共同 $\epsilon=2\max(\sigma_r,0.05)$ 作为**诊断**，不当作联合 95% 门限。[判别代码](../../../research/sonar_range_factor_v2/models.py#L83)。

| 样例 | 可核验结果 |
|---|---|
| M0 假零残差 | $d_a=d_b=20$ m、$r_a=r_b=5$ m、两个接收器等高且共水平点；M0 恰为零，$\eta_a=\eta_b=-375$ m²。M1 的原距半平方代价为 225（单位白化），确无原距可行解。 |
| 正确关联、正确量程，接收器同/不同高 | 合成精确距离的根交一致；测试同时覆盖正/负接收器高差与近等高。 |
| 交叉或反向航线、大小横向基线 | 用解析几何生成，验证根不依赖左右舷符号或航向标签；不同真实位姿仍产生不同 $\eta$。 |
| 错配和量测噪声 | 单视图人为量程偏差及交换其它地物实际回波的扰动都测了；零容差可能拒绝正确匹配，扩大容差也可能放过错误匹配；两种都不是关联判真。 |
| 区间端点和多个视图 | 覆盖上／下端、四视图共同高度、最后两视图相对漂移；额外测试共址天底非光滑点，不给出伪微分。 |

全部计算对**同一批候选**进行，列表见[单测](../../../tests/test_sonar_range_factor_research_v2.py)、[合成扫描数据](MONTE_CARLO_RESULTS.md)。在真实系统里，$\eta$ 与求解位姿同时变化。错误位姿、地图偏差、声速误差、舷侧重复外观都能造成严格判别不通过，初始姿态处硬剔除可杀死有用回环。建议记录各候选根和 $f$；若需接受/拒绝，用独立校准后的协方差和哨兵规则，按初始化误差、几何条件和同一地图来源试验误拒/漏拒。当前未向正式导航增加门控。
