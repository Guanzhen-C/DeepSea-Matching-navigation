# 统计一致性：公共误差、标定和验收

## 1. 误差项不能按行随意相加

对 $q_i=\rho_i-r_i$ 的小扰动，设 $s_i=v_i/\rho_i,\ b_i=(Z-z_i)/\rho_i$，有

$$dq_i=s_i^\top dL-s_i^\top do_i+b_i(dZ-dz_i)-dr_i.$$

如果 $do_i$ 来自局部插值姿态、杆臂旋转和平移，它与图状态和其他 $do_j$ 相关；若误差已被真实图变量显式估计，不应同时作为独立噪声重复加入。声速和时延零偏在 $r\approx c(\tau+\delta\tau_0)/2$ 的线性化中分别给 $\rho_i\,dc/c$ 和 $c\,d\tau_0/2$。同航次声速、时钟常数可以同时改变每一行。对正确关联的候选，建议把

$$\Sigma_q=D_R+\sum_k G_k\Sigma_kG_k^\top+\sum_{k\ne j}G_k\Sigma_{kj}G_j^\top$$

作为有效预白化模型；其中 $D_R$ 是剩余接收和量程噪声（也未必对角），$G_k$ 按上式写，共享变量也可显式估计。对共享地图位置，$G_L$ 的第 $i$ 行是 $s_i^\top$，所以跨接收协方差是 $s_i^\top\Sigma_Ls_j$。相同采样列的复用、邻近波束、重叠 ping 时窗、复脉压、同地物地图误差都可能造成相关。物理身份错误、明显多径或截距漂移应分成混合/重尾或偏置，而不是用一个更大的固定高斯标准差遮掩。

回环和地图匹配与原距可能消费相同子图或来源 token；高度共用不能消掉这部分。主试验中应记录来源 token、ping、通道、时窗、底图块和轨迹编号。先比较**按来源排他**和显式共享变量／块白化；只有不知道具体交叉项时才用经盲集覆盖率标定的膨胀。使用同一特征同时算历史回环和原距的单一示例只是展示功能，不证明信息独立，也不可用各自的 Hessian 直接相加得出可靠置信区间。

## 2. 标靶和真实数据怎么量

| 项 | 实施方案 | 要锁定的混淆 |
|---|---|---|
| 测距与采样 | 用位置、高度可追溯的反射标靶，多个已知声程、舷侧、束号、频带；重复静态发射和跨线覆盖。记录原始 IQ、采样频率、触发时钟、脉压峰/距离估计，按距离和信噪比分层拟合偏差/方差以及沿程和跨波束残差相关 | 量距中心、拟合波峰和导航重采样栅格并不等义；须追溯标定前后时间/列 |
| 声速、时钟 | 同期测声速剖面，正反/多距离路径；对已知几何拟合观测距与真距的比例和常数，共同估计 (或独立硬件量测) 时间零偏，跨日验证 | 只有一档距离会把比例与常量混为一谈；折射严重时改声线模型，不能只调 σ |
| 相位中心、压力 | 独立杆臂测量＋倾斜/不同深度重复探测，拟合角度依赖的通道相位中心及残差；深度计用稳定刻度、水密度校正和独立参考检查零漂 | 姿态、竖向时延、杆臂、声速可相互补偿，至少覆盖两个高差和多艏向 |
| 地图 XY | 独立测绘地图与重复目标标注，估计全局刚体偏差、局部各向异性协方差及空间相关长度；明确地图测量不由被评分航线生产 | 同航次地图与查询可能共用 GPS/声学导航；需独立地图或明确报告交叉相关 |
| 关联 | 记录人工／标靶真值对应，按纹理、舷侧、航向和遮挡分层，估计错配、错误合并及漏检率，并在不同航次盲测 | “两点低代价”不能作真实关联标签；外点受重复地纹聚类和数据选择影响 |

当前 M0 的 $0.7,2.5,1,0.03$ m 是工程默认；合成配置中给出的 σ、独立来源和理想时钟均不是实采标定。原型在地图误差扫描额外用初值/固定高度处的一阶 $G_L$ 和同一已知模拟 σ 形成整地物块 $\Sigma$，没有使用真值姿态或真地物高度为白化。该近似也没有地物间地图相关或与派生地图/回环因子共享的完整建模。

## 3. Monte Carlo、NIS/NEES 与航次 Bootstrap

在明确的线性高斯校验中，取 $S_y=APA^\top+\Sigma_q$，以独立先验形成 $\nu=y-A\hat x^-$；NIS=$\nu^\top S_y^{-1}\nu$，自由度为有效创新秩。独立真值下，NEES=$(x-\hat x)^\top P_{\rm post}^{-1}(x-\hat x)$，自由度为可信状态维数。用理论阈值统计覆盖和均值，且报告几何分层。压缩掉高度自由度后只可对合适的白化创新子空间计数；非线性、剖面截断、模型选择或复用测试集得到的残差并非普通卡方，需用独立仿真／实测重新校准。不能直接把鲁棒目标、残差行数或平滑后重算的误差当成 NIS。

本轮[线性联合误差对照](MONTE_CARLO_RESULTS.md)只检验上述流程：6000 个线性高斯 draws，使用真协方差与人为丢掉非对角元素作比较，**没有**证明 M1/M2 非线性外场的 95% 一致性。合成定位扫描用模拟航段为单元，成对重采样同一随机种子的误差，不以 ping 数虚增显著性。实地要按独立航次/日为外层 bootstrap，必要时内层以间隔大于相关长度的整条航线为分块，报告覆盖和失败航次；不能把同一套 32 种子在多个扫描水平的重复当作额外独立样本。
