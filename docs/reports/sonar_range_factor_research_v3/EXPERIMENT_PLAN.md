## 扩充冻结重放

从 [第四阶段](../sonar_range_factor_research_v2/EXPERIMENT_PLAN.md) 提取多个已审计输入流。按时间边界重建固定滞后与越窗处理，比对同一因子从“可用”到“发布”的延迟，加报 no-range、M0、M0_plain、M1_Gaussian/M1_Robust 与“禁历史回环”的交互组。保持同样观测关联和起点，使所有出入时间、回环先验和评价节点相同；固定图若缺少逐对原距协方差，预先指定一组相关模型并报告敏感性，不能调到测试误差最小。M2 需要确证每个物理 track ID 和 token 跨窗不重；现有归档不能把近邻 XY 当作身份。

## 闭环和真实航次

1. 只在独立实验入口接 GTSAM M1，不改正式入口。先 shadow 模式并列产生 M0/M1 候选；记录区间 gap、峰值时延、何时死区失效、活动边界切换、非有限及跳点。故障必须可核验回滚；在硬件负载和真实数据上实现测得的 deadline 才能宣称符合采样。
2. 冻结底图、初始化、导航运动设定、去噪、输入种子、阈值、检查点回放；闭环允许估计影响后续关联，另与固定关联结果分开。验收用原速时间戳对齐平面 RMSE/P95/最大、RPE、末端、丢失/恢复、耗时和内存，失败不删除。独立日/航次 bootstrap，统计量对相关范围分块。
3. 用多深度、多航向和重复纹理的标靶/独立湖海数据分层测真实量程误差、声速、时钟、压力和相位中心；以独立位置真值评分。不得用同航次匹配底图生成的位姿既训练又评分。鲁棒参数只在标定集定，留出多地形独立验证。
4. M2 准入条件必须五项同时过：可靠身份、多视角独立增益、错误合并受控、完整图稳定、计算和内存可接受。目前仅受控等价/可观性证据，维持扩展。

**准入顺序：**先判成功率及失败恢复，再比较精度；若 M1 只在大垂向变化、低污染且稳定分支条件有增益，允许它成为受约束的候选策略，不要求全域替代 M0。
