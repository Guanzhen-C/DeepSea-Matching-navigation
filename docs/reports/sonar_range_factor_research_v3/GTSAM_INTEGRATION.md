# GTSAM 集成准备：双 Pose2、固定目标和回退

[独立适配器](../../../research/sonar_range_factor_v3/adapter.py)接收同一地物两次斜距、两节点各自水平方位/杆臂、垂向估计和冻结的原距协方差。输出 2 维白化后的有符号鲁棒向量；图上使用 Unit(2)，不得再用 $\Sigma$ 或额外 Huber 重复白化。用第四阶段的剖面导数，对每个节点将世界加法 Jacobian 乘 $\mathrm{diag}(R_i,1)$，对 GTSAM 的 Pose2.retract 进行匹配。[GTSAM 官方 CustomFactor](https://gtsam.org/tutorials/intro.html#defining-custom-factors)。

**接受域。** 唯一、稳定内点或严格固定边界才返回常规导数，等高固定上界的结构性零坡度按第四阶段专门分支处理。被判为并列最优、高度曲率过小、真正边界切换、浮点区间未解析或天底零预测距离时，不返回假零导数。严格界求解器目前不在 callback 运行，快速路径成功不是严格证书。正式接入需要信赖域策略处理可恢复试探步、受控预算及统计监控。

**回退合同。** [批处理/增量控制](../../../research/sonar_range_factor_v3/adapter.py)要求 builder 提供不可变的观测序列，分支固定后才构建图。M1 抛出可识别的失败时，丢弃本轮 LM/iSAM2 实例，用同一观测和初始状态重建 M0 图；不留部分更新，不在单个 callback 内静默换成本。M0 也失败则原样暴露。此处为全量重放研究策略，不是生产在线热切换；长图应以可核验 checkpoint/replay log 约束救援时延，并区分数据错误、数值异常和外层优化器失败。禁止事后用真值挑选哪个分支。

**已验证。** 独立测试执行 GTSAM 局部切空间差分（相关白化和 Student-t 向量）、LM 成功、两轮 iSAM2 增量成功、M1 并列高度时 LM 和增量已加入早期节点后重新以 M0 回放。固定历史图重放另实际使用冻结 runtime 的地图先验/回环/里程计/规范锚 GTSAM 因子，逐边替换斜距，不引入旁路优化结果。

**未验证。** 实时固定滞后、map→odom、在线重线性化下的活动切换，在真正长航程、真实独立数据、Jetson 帧时延及回退重放上尚未测。Python 当前对每个 M1 观测对建一个 factor；同样 19 批/202 对，回放 GTSAM 条目从 M0 的 352 增至 M1 的 535，既有位姿仍是 198。应以同一节点对批处理 2n 行、缓存重复剖面初值并做精度门限；这些是待实现/待测，不据此承诺加速。
