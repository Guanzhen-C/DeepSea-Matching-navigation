# M1 全局高度剖面：严格界与工程求值分离

固定两个节点，$d_i^2=\|L-o_i\|^2,\ q_i(Z)=\sqrt{d_i^2+(Z-z_i)^2}-r_i$。对固定白化矩阵 $C$（$C^\top C=\Sigma^{-1}$），联合高斯目标为 $F(Z)=\tfrac12\|Cq(Z)\|^2$，区间 $I=[a,b]$ 位于下视支 $b\le\min z_i$。$F$ 在紧集连续，存在极小值；\(\rho=0\) 时可求值但不能使用常规导数。一维全局目标不意味着外层姿态图全局凸。

## 可证明的高度范围和驻点

当 $\rho_i>0$ 时，令 $B_i=(Z-z_i)/\rho_i,\ D_i=d_i^2/\rho_i^3$，有 $g=(Cq)^\top CB$，$H=\|CB\|^2+(Cq)^\top CD$。内部候选包含 $g=0$；边界须单列。光滑下界必要 $g(a)\ge0$、上界 $g(b)\le0$；严格不等式可维持活跃集，没有严格性不能一般套用光滑 Hessian。全区间下界 $H>0$ 保证严格凸和唯一最优；一般带相关的二次型不保证该条件。第四阶段的等值反例 $d=(1,0),z=(0,2),r=(2.8125,1.8125),I=[-4,0]$ 中，边界 $Z=0$ 和内部 $Z=-0.75$ 的全局代价均为 1.66015625；另有一个内部局部最大值。证明见[上一阶段](../sonar_range_factor_research_v2/MODEL_M1_PROFILED_RANGE.md)。

[严格实现](../../../research/sonar_range_factor_v3/certified.py)对每个标量算术的下界取 FLOOR、上界取 CEILING。平方根采用 Decimal 的正确最近舍入，再取相邻可表示数向外包络（[Python Decimal 文档](https://docs.python.org/3/library/decimal.html)）。乘法取四个端点，区间平方跨零明确用下界 0。用高精度 Decimal 精确转换已有二进制浮点，连 $C$ 的矩阵乘法也逐项包络，不把已经舍入的 $C^\top C$ 当作严格等价的实数矩阵。

- 对区间 $X$，用 $\frac12\sum e_i(X)^2$ 给直接下界；若 $g(X)$ 同号，取单调端点下界；否则再用 $F(m)+g(X)(X-m)$ 的均值定理下界并取较紧者。对有合法输入的高度点，以该点上界作为全局 $U$；最低活跃箱下界加上已剪枝下界的账本给全局 $L$。只有箱的下界大于 $U$ 才剪，不把可能存在的并列最优提前删掉。
- 另一条流程单独覆盖**全部内部驻点**：若 $0\notin g(X)$ 则排除；$H(X)$ 严格同号、端点导数严格同号也可排除；$H$ 有严格符号且端点导数反向时，连续性及单调性保证该箱恰含一个相应型的零点。其余细分。达到高度分辨率的可能箱、奇异箱或预算未解箱均原样返回；不是“已唯一定位所有驻点”。若根刚好落在二分边界，可能有两只候选箱。
- $U-L\le\epsilon$ 是**目标值的绝对误差证书**，不是最优高度误差、全局最优个数或外层位姿最优性证书；最佳样本 $Z$ 不必是精确根。预算/超时/精度状态保留当前证书区间，不说“已收敛”。延时是在分裂之间轮询；不构成硬实时截止。上游输入不有限或空物理区间直接报错。

## 严格结论的边界

证书只对传入的、已表示为二进制数的 $d_i^2,z_i,r_i,C,I$ 所定义的精确实数目标成立，且假定 Python Decimal 实现遵循其有界指数和舍入语义。位姿的三角函数、XY 相位中心组合、协方差传播和 Cholesky **没有**在此严格包络，亦无设备标定保证。原型消费者使用第四阶段快速浮点剖面，而非每次图线性化都算严格证书。实验只交叉检查所列严格样例；不宣称快速路径全域受认证。若部署需端到端证明，应为三角函数、误差模型和线性代数提供可证明封套并计入截止预算。

对单调的径向损失 $\phi(2F)$（Huber、Cauchy 罚函数、Student-t 或常密度混合）高度极小点集合与高斯一致；严格证书直接作用于 $F$。若需要 robust 代价值的严格数字上下界，仍需对 log、sqrt 等外层运算做独立向外舍入。逐通道污染混合、随 $Z$ 改变的协方差或外点密度则可能改变最优高度，不能复用此结论。
