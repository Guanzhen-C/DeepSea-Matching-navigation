# M1 鲁棒原距似然

对原始双距 $q=(\rho_a-r_a,\rho_b-r_b)^\top$ 保持向量，完整白化 $e=Cq$；令 $t=e^\top e$。不能把 M0 的标量平方差鲁棒核直接套在两个未白化分量上：相关观测的自然尺度是椭圆距离，径向 Loss 对正交白化的选择不变。相反“每一白化分量一个 Huber”会随白化基改变。

| $\phi(t)$（忽略与状态无关的常数） | 含义 |
|---|---|
| $t/2$ | 高斯负对数似然 |
| $t/2$（$\sqrt t\le k$）或 $k(\sqrt t-k/2)$ | 径向 Huber，外侧保留有界径向影响；本轮 M1_Robust |
| $(k^2/2)\log(1+t/k^2)$ | Cauchy 形罚函数；不得将其中的 $k$ 当成一般多维 Cauchy 的标准差 |
| $[(\nu+d)/2]\log(1+t/(\nu-2))$ | $\nu>2$ 的多元 Student-t（$d$ 为白化维数），这里 $\Sigma$ 表示**协方差**，其分布尺度为 $(\nu-2)\Sigma/\nu$；真实 Cauchy 即 $\nu=1$，无有限方差 |
| $\log(A+B)-\log(Ae^{-t/2}+B)$ | 对内点高斯＋固定支持上常密度外点的整块混合；$A/B$ 含内外点先验赔率和原距空间单位一致的零点密度比 |

Huber 的经典出发点是污染模型下的位置估计（[Huber，1964 原文](https://projecteuclid.org/journals/annals-of-mathematical-statistics/volume-35/issue-1/Robust-Estimation-of-a-Location-Parameter/10.1214/aoms/1177703732.full)）；重尾可参考[Lange、Little 与 Taylor，1989 作者文章 DOI](https://doi.org/10.1080/01621459.1989.10478852)。当前这些损失的代价和变换均有单测；主扫只对预先冻结的 Huber 做实验，不事后挑选 Student-t 或 Cauchy 的最好曲线。

因为整块 $\phi$ 单调，固定 $p$ 的高斯与径向鲁棒使用同一个 $Z^*$。鲁棒核**不会**让单个坏视图从拟合高度中自动消失，只降低整对对位姿影响。可疑关联的真实模型可把每个视图的 valid/invalid 身份设隐变量，带一侧污染时使用剩余条件似然；必须重新做高度搜索、可观性与错误关联风险验证。当前常数密度混合是研究对象，支持边界、外点率、地图错配机制并未由真实资料估计。

不取 $\sqrt{2\phi}$ 作标量残差。用 $\tilde e=a(t)e,\ a(t)=\sqrt{2\phi(t)/t}$。$t>0$ 时导数为 $aI+(2\phi'(t)/a-a)uu^\top,\ u=e/\sqrt t$；$t=0$ 取 $\sqrt{2\phi'(0)}I$。其半平方与目标严格相等，避免零点绝对值折角；活跃集切换的光滑性仍由高度剖面决定。[代码](../../../research/sonar_range_factor_v3/likelihood.py)。

噪声传播使用 $\Sigma_q=R+G\Sigma_\eta G^\top$。$G$ 分别包括地图 XY、各相位中心 XY、接收高度、共同 $dc/c$ 和时钟零偏 $dt_0$ 的偏导；同地物地图项横跨两视图，参数协方差允许非对角。若导航状态已经估计该偏差，不能当量测噪声再计一次。当前白化冻结于先验位姿和公共标称高度；更新 $C$ 时要考虑协方差的导数与高斯 logdet，不能边拟合边改权重而仍声称同一似然。不同因子共享的同航次地图/时钟/历史回环相关未由 2×2 白化自动消除。

独立标定：在未用于定位比较的已知标靶上，跨距离、通道、姿态和高差测量分贝信噪、声速、同步、杆臂和压力基准；拟合 $R$ 的相关和偏差，估计幅度/距离分层尺度、污染概率；冻结后按整航次盲测。对预报创新用独立协方差做 NIS（及有真值时 NEES），航次级 bootstrap，严禁以 M1 拟合高度后变化过的残差直接按原 2 自由度卡方。第四阶段 [6,000 样本的线性一致性对照](../sonar_range_factor_research_v2/MONTE_CARLO_RESULTS.md)可作为验收流程，不是本阶段实测标定。
