# 论文贡献和推荐选型

当前建议：**M0 继续正式运行；M1 作为论文主要待验证候选；M2 保留扩展。** M1 解决了 M0 的基本物理可行性不足：在所假设的下视直达且完整 SPD 原距白化条件下，零剖面代价意味着两个原距可由一个共同高度解释。严格高度值证书和非光滑故障输出让这一数学主张可核验。统计模型也从“一个平方差标量”转到“相关原距向量”：按整块稳健，并保留协方差。**没有**由此保证真实定位必然更好。

可作学术增量的结构是：给定水平地图且地物高度未知，推导一个有界原距导航因子，明确完全相容、外点置信及可稳定微分的域，并比较其与差分、回环、多视共享在相同数据上的性能和失败。通用全局区间算法、包络定理、Huber/Student-t、Schur、GTSAM、已有双斜距几何都不能认作自创。对照[已使用原距与扫掠平面的 Zhang 等论文](https://arxiv.org/html/2312.13802v2#S3.SS3)和[两侧扫观测的二视图几何](https://arxiv.org/html/2609.25271v1#S4)，本项目的细分区别是**固定水平参考图、只剖面高度且直接连接两个待估姿态**。第五阶段验证的是具体工程数学链路，尚不构成普适的统计一致性或优先权证明。

| 选择 | 推荐使用情形 | 不能依赖的假设 |
|---|---|---|
| M0 | 当前正式导航、时延紧、原距相关性未知、强错配或 M1 非光滑 | 差分零不等于两原距存在物理解；非等高死区可能无一阶信息 |
| M1_Gaussian | 经标定、洁净且高差明显，作物理基线；离线分析 | 不抗错配，不能用低残差鉴别身份 |
| M1_Robust | 作为下一步主原型；需已冻结原距尺度和可信关联、光滑工作点及确定的回退预算 | 块核不会修正错误高度模型；对严重错配和固定历史图并未全面优于 M0 |
| M2 | 已验证轨迹、真正重复视图有多方位且成本可接受 | 地物多不等于独立信息；错误合并会污染全轨迹 |

投稿前优先补两类结果：一是标靶和实际多航次估计 $\Sigma$、错配及相关长度；二是冻结重放扩至多个航线，做真实在线消融和独立真值盲测。保持方差假设、计时范围、失败比例显式可追溯。可以报告高差合成优势和固定图负例，但不可从某一受控增益外推出实测改善。
