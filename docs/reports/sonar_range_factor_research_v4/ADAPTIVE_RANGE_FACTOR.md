# Adaptive Range Factor：因果门控和回退

输入是两条原始斜距/量程格及其 provenance、地图 XY、两时刻的相位中心和垂向估计、协方差、当前剖面输出，以及独立标定的关联概率或“未知”。档案可证明 token 与 pair 来源，不等于知道任何关联概率。因此本轮历史评估全部将置信度设为未知，没有把旧匹配 score 当概率。对每条边校验两节点初始化时间不晚于接收窗到达，**只用该边已到达的数据和节点初始估计**；远程历史已知但不读取将来的输入、最终平滑轨迹或者真值。真实接入应使用插边时的因果运动预测与协方差、时钟及相位中心，不应简单把历史静态档案初始化等同于最新可信预测。

## 检查与动作

1. 检查上游有限值、SPD、量程/时间、原 M0 与新行的来源一致。对于标定关联概率低于拒绝线的行直接拒绝；弱置信但不拒绝的行采用降权 M0。没有可追踪来源的档案不构造任何伪因子。
2. 尝试扩展原距的下视物理解：计算每视图观测带 $[r_i-k\sigma_i,r_i+k\sigma_i]$ 的未知高度反像；需要所有反像与下视区间有交。失败表示**当前预测**下原距不相容；不能断定散射物必定错配，所以未知定位协方差时保守用 M0，而不按真值硬拒绝。这个逐视图管道不是有独立真值的联合置信区间。
3. 用 M0 的米制差分死区标准化宽度 $\frac{2|\Delta z|(R_{\max}+6\sigma_p)}{(r_a+r_b)\sigma_{M0}}$ 衡量是否值得启用 M1。M0 死区窄时保留 M0；否则要求 M1 批剖面在固定工作量内得到稳定候选、非奇异、非切换，曲率足够、离物理边界有余量、剖面创新未过大。查到两个极小/近等价、预算不足或非光滑交还 M0；这不宣称 M0 与 M1 物理等价。
4. 每一行只用一个模型，**不叠加同一对的 M0、M1 信息**。M0 保留原批预算（弱置信再做乘性降权），M1 沿用总行上限归一及未知置信度折减；对残差乘权重的平方根。不给无协方差验证的权重概率最优解释。
5. 在加入 GTSAM 前锁定每项选择及维数，线性化时不实时更改模型。如果 M1 在优化过程中离开有效图表，丢弃失败求解器，并从同一初始化把原先 M1 行重建为 M0；保持既有拒绝和弱置信策略。批处理实际没有触发该回退（因为档案全 M0），合成测试检查了模型锁定与恢复的接口。这是工程上的瓦解保护，**不是同一个似然目标**。

## 门限与结果

[冻结配置](evidence/policy_frozen.json)用独立的 240 个合成接收对（seed 792043），不读取导航评价。原距带从声明的候选尺度选，定为 2.0σ；剖面半平方代价对应的半径限 2.3113；低垂向组死区标准化 75% 分位生成下限 4.2362。曲率下限 0.015625、边界距 0.50 m、128 个箱预算、置信 0.35/0.80 和信息系数 0.5/1 是预声明工程设定，不说已由真实数据标定。配置在盲评前冻结，三个现场仿真档案评完没有回调阈值。半径限制和物理带仅适合已声明的条件范围。

三个历史仿真全选 M0；这仅证明保守门控与 M0 回归一致，**未证明 Adaptive 在历史导航中能用 M1 改善精度**。[独立合成选型控制](evidence/validation.json)另证实门控不是无条件保留 M0：大高差、可行阵列存在成功 M1 分支，低高差、明确低概率和明显不相容各走各的路径。合成不是航程实测。下一步增加真实插边时刻预测不确定度与独立标靶关联概率，重新冻结标定而非降低阈值迎合这三条测试轨迹。
