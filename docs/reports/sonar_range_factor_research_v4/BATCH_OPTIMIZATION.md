# M1 计算优化：保留全局候选和故障状态

## 1. 计算路径

对于同一对 Pose2 下的 $N$ 个地物，各点的地图 XY、两次接收杆臂/垂向/量程、物理区间以及白化 $C$、精度 $W$ 均固定。批因子构建时一次性堆叠；试探步只计算两份位姿旋转、所有水平平方距离 $d_i^2$、候选和导数。不会每次调用重新分解协方差。两位姿值完全相同且计算策略相同，残差、雅可比和状态用同一份不可变缓存；姿态一变重算，不用近似缓存。热启动高度**只用在已找到的单调驻点括区内**，不能减少全区间候选。

分支对以下函数操作：$e=C(\rho-r)$，$F=\tfrac12 e^\top e$。$\rho'=(Z-z)/\rho$、$\rho''=d^2/\rho^3$；对下视单调分量的端点包络和第五阶段同源。将各地物尚可能存在局部极小的箱拼在数组里；当导数区间不含零或曲率全负时剔除内部极小候选，当曲率严格正时检查端点导数并做有括区 Newton/二分，其余箱细分。上下界始终作为候选，近等值/近退化分支交还标量参考。纯 M1 行失效后整因子显式失败，不静默删除行；Adaptive 的预判不允许在预算内完成不了时私自调用重的标量流程。[实现](../../../research/sonar_range_factor_v4/batch.py)。

这些剪枝是数学包络的**浮点实现**，含基于运算项尺度的防护余量，不等价于定向舍入证明。严格目标界仍由[第五阶段 Decimal](../sonar_range_factor_research_v3/M1_GLOBAL_SOLVER.md)独立做抽样复核。两个求解器都只约束固定 Pose2 时的高度；不声称导航图全局最优。不支持的天底、并列、切换、未解析和预算状态保留。残差向量保持光滑分支的隐式高度导数；批量计算 Gaussian 精确剖面 Hessian $H_{pp}-H_{pZ}H_{ZZ}^{-1}H_{Zp}$，固定边界时使用 $H_{pp}$。Huber 路径使用白化残差和链式变换后的 Jacobian；输出的 Hessian 仍为 **Gaussian 剖面 Hessian**，GTSAM 使用鲁棒残差的 GN 线性化，不把二者混作鲁棒精确 Hessian。

## 2. 实际一致性和耗时（本机 PC）

[收据](evidence/batch_benchmark.json)使用 24 个独立种子，等/近等/较大垂距、航向及相关协方差。144 个独立双距对均与标量参考一致，无状态分歧；每组第一对再核对 Decimal 严格值证书，24/24 覆盖（比较留了浮点目标的 $2\times10^{-10}$ 余量）。最大绝对差：高度 $1.26\times10^{-12}$ m、代价 $1.85\times10^{-13}$、残差 $5.41\times10^{-13}$、世界雅可比 $1.25\times10^{-12}$、Gaussian Hessian $3.59\times10^{-11}$。退化分支和预算另外走单测，不以这 144 个成功样本代替故障验证。小图最终误差的最大差约 $6.22\times10^{-14}$ m。

| 测量对象 | 中位耗时 | P95 |
|---|---:|---:|
| 标量 M1，48 对 | 18.218 ms | 38.131 ms |
| 批量 M1，48 对冷启动 | 1.949 ms | 2.734 ms |
| 批量 M1，位姿轻微变化 | 1.682 ms | 2.451 ms |
| 批量 M1，完全相同位姿缓存命中 | 0.00769 ms | 0.00907 ms |
| 标量 M1，小图优化 | 74.373 ms | 146.445 ms |
| 批量 M1，小图优化 | 35.490 ms | 68.152 ms |

48 对测速为 6 个独立地物 × 8 重复以隔离同节点对负载；一致性计数用每个场景的 6 条独立原距对。移动位姿耗时不能单独用来归因热启动，因为搜索难度也随位置变。缓存命中不等于实际工作速度。小图为相同数据的阶段五问题（合成二维漂移、Python 单线程运行），批量冷启动 9.35×、整体 2.10×。没有达到整个优化十倍，更没有证明实时 5 Hz。固定图的实际墙钟见[多场景](FROZEN_GRAPH_VALIDATION.md)。

## 3. GTSAM 和 C++ 可行性

用一个 $2N$ 维 UnitNoise CustomFactor 连接两个 Pose2，原量程仍为每个地物两行；按原顺序叠栈与 $N$ 个旧 $2$ 维 M1 因子代价和 Jacobian 相同，无重复白化。[批因子](../../../research/sonar_range_factor_v4/graph.py)的局部 Pose2 导数经有限差分对比。

本机 Eigen 3.4.0 编译通过 [已隔离的凸括区微内核](../../../research/sonar_range_factor_v4/eigen_height.hpp)和[数值探针](../../../research/sonar_range_factor_v4/eigen_probe.cpp)，在已知根 −11 m 上核对了成功、空预算、坏括区。它不是全局箱枚举器，也未加载到 Python/GTSAM 主试验。下一步将箱枚举和向量化白化一起封装为单次 native 调用，并在同样的退化及证书集上验证；禁止 fast-math 抹掉异常及改变区间假设。Eigen 固定尺寸矩阵参见[官方文档](https://libeigen.gitlab.io/eigen/docs-3.4/group__TutorialMatrixClass.html)。
