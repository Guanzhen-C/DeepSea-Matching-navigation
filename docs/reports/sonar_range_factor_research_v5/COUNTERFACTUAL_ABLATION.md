# 反事实消融：固定图、同 token、不等于因果

## 实验约束

每个模型使用相同图节点初值、规范锚、地图先验、里程计、历史回环，GTSAM LM 上限 60 次。所有删边臂从同一个初值重跑，不用完整后验热启动，原有每批残差权重不因删边而再分配。所有关联和选择已经冻结，真值在优化完成后才按相同时间戳评分，未做 SE2 事后对齐。两模型对照仅 M0 vs M1_Robust；M1 的相关系数假设有另行灵敏度，不把阶段六的纯高斯失败冒充当前结果。

| 臂 | 实际操作 |
|---|---|
| A / B | 完整斜距 / 不要任何斜距，其他边（包括历史回环）保持不变 |
| C | 对每个已插入的批单独删除；共 304 批 × 2 模型，608 次尝试，**5 次失败保留** |
| D | 用归档到达时间除以观测总跨度，在相同时间轴分四段，各次删除该段全部斜距；空段也运行。不是用真值里程切段 |
| E | 删除与历史回环相同目标及相同决定时刻，或有相同图端点的批；这是**同窗相关风险的代理**，不是已测的跨因子协方差或逐 token 确证 |
| F | 用计算前已冻结的绝对门槛和比率：仅当两个模型条件目标 XY 的第二奇异值均达不到 0.10 和第一奇异值 10% 的组合要求才删；这是几何保守筛选实验，未用历史误差调节 |
| G | 仅保留通过 F、无 E 风险，且因果代理的原距可行管通过率 ≥60% 的批 |
| H | A 的两模型共享所有原始双距来源；有序 token 经摘要验证，M0 与 M1 的量纲和统计目标不被强行等同 |

## 固定图节点平面 RMSE（m）

每个单元格顺序 M0 / M1_Robust。所有 A/B/E/F/G 给出返回解。

| 档案 | A 完整 | B 无距 | E 去同窗风险 | F 去几何弱批 | G 只保留高质量 |
|---|---:|---:|---:|---:|---:|
| 16.49 km | 1.541 / 1.524 | 4.760 / 4.760 | 4.024 / 4.000 | 4.805 / 4.829 | 4.805 / 4.829 |
| 4 km | 1.355 / 1.459 | 4.125 / 4.125 | 2.022 / 2.015 | 4.125 / 4.125 | 4.125 / 4.125 |
| 2 km | 1.920 / 2.055 | 1.369 / 1.369 | 1.562 / 1.622 | 1.369 / 1.369 | 1.369 / 1.369 |

F 和 G 在 16.49 km 都只留下 **1 批（8 对）**，其余两档没有任何批保留，故 G 不是一个有效的部署策略。E 在 16.49/4/2 km 分别删了 238/14/5 批；结果随环境相反，**不能把同窗当作坏因子标签**。

### 单批与多批

| 档案、模型 | C：删后变坏 / 变好 / 小于 1 mm / 失败 | 最强删后变坏 / 变好 |
|---|---:|---:|
| 16.49 km M0 | 63 / 34 / 180 / 0 | 0.1084 / 0.0329 m |
| 16.49 km M1 | 61 / 37 / 179 / 0 | 0.0975 / 0.0402 m |
| 4 km M0 | 11 / 8 / 0 / 0 | 0.3184 / 0.0823 m |
| 4 km M1 | 7 / 6 / 1 / 5 | 0.0951 / 0.2024 m |
| 2 km M0 | 4 / 4 / 0 / 0 | 0.1612 / 0.5315 m |
| 2 km M1 | 5 / 3 / 0 / 0 | 0.2081 / 0.7602 m |

D 的交互量为 $\left[\mathrm{MSE}_{-S}-\mathrm{MSE}_{A}\right]-\sum_{j\in S}\left[\mathrm{MSE}_{-j}-\mathrm{MSE}_{A}\right]$，单位 m²。16.49 km 的 Q4（删除 92 批、935 对）使 RMSE 变为 2.286/2.268 m；交互余量 **+2.197/+2.308 m²**，表明独立的小影响不能相加解释航段贡献。4 km 的 Q4 M0 改为 4.156 m、余量 **+14.652 m²**；M1 多个 C 样本失败，所以不能给伪造的相加余量，Q3 整段删减本身也失败。交互余量来自共同优化、代价与评分的非线性，不是物理独立性证明，不可将其称为严格因果效应。

### 协方差敏感性（额外对照）

令 $\rho=-0.50,0,0.50,0.75$，对每个原距对令差分投影方差恒等于归档值。16.49 km M1 RMSE 仅在约 1.523–1.524 m 变化；2 km 约 2.052–2.066 m；4 km 在 −0.50 和 0 的 M1 路径失败，而在 0.50/0.75 返回约 1.460/1.461 m。该试验**没有**从误差选出真实 $\rho$，也不说明其他协方差项无关。
