# 学术结论、限制与推荐选择

**本轮不足以宣布一个在导航上已验证的新自适应斜距约束算法。** 第七阶段的价值是把原因分开：可追溯原距的物理失配、局部几何及跨因子共同作用、选择策略的预测来源和置信度。不以单个系数大或单次仿真改善冒充稳健启用证据。

1. **可防守的数学/工程结果。** M1 从原始双距剖面中恢复 M0 差分死区中遗漏的一阶方向，前提是稳定剖面与互补几何；物理相容、几何有效和最终定位误差是三种不同的命题。批量内窥和逐边留一提供可复核的强/弱与非加性框架；因果前缀代理只能用于诊断历史初始化为何不合适，不能替代实际预测。等效短路避免无效剖面而保持模式/权重不变；这是一项可明确描述的实现改进，而非新的测量几何或历史精度增益。
2. **何时保留 M0。** 近等深、需求低时延、协方差尚未校准、且匹配可信时；阶段七近等高历史为此提供有限的固定图证据。即使当前局部 Jacobian 接近单方向，也可补全轨迹整体：16.49 km 的结构筛选或删除同窗批次明显降低性能。另一方面短程维持全图可能有害，不能无条件信任 M0；其零残差不证明两个原距具备共同物理解。
3. **何时保留候选 M1。** 非等高导致 M0 丢有效信息、标靶身份和原距可用且白化可靠、方位/基线不共线时。受控 4 m/16 m 高差及低噪声体现此条件，尚缺真实变深航线的独立真值验证。不同 $\rho$ 或删边改变试探位姿，部分 M1 仍失败。M2 保持扩展，不把历史平均地图位置当作可信共享靶标。
4. **不能独立归属的先例。** GTSAM、剖面、Schur、鲁棒和留一消融本身不是原创；已有 [Zhang 等侧扫原始距离/扫掠平面模型](https://arxiv.org/html/2312.13802v2#S3.SS3)。本项目若形成贡献，应归属给定地图 XY 但地物高程未知条件下、来自可验证接收对的有界导航约束，以及实际诊断和自适应在留出数据上的额外价值。没有独立外场证据前，最多作为待验证的系统方法，不能写“首次”“实时”“普遍优于”。

稿件可以现在使用：固定图 A/B/C/D 真实负例、局部/全图互补以及“不凭残差选模型”的实验。投稿前必须补标靶含同步 IQ、真实协方差、跨航次关联真标签和独立位姿；冻结新策略后验证有足量有效切换，观察在线完整窗口、失败恢复和端到端延时，见[数据清单](MISSING_MATERIALS.md)。既有 M0 保持正式导航，不在本轮切换。
