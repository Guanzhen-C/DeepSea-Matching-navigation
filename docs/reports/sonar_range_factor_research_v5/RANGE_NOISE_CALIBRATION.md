# 原始双斜距噪声：用 IQ 和独立标靶标定

**未获得真实标靶的可追溯量距参考，本轮没有测出实装的 $\rho$。** $\rho=0.25$ 是旧图对照的显式假设；只知道差分方差 $g^\top\Sigma_rg$ 不能反演两方差和互协方差。也不能从 M0/M1 的定位误差选一个最佳 $\rho$ 再当物理测量。历史仿真变动见[灵敏度](COUNTERFACTUAL_ABLATION.md)。

## 1. 从接收到独立量距参考

1. 保留原始复 I/Q（若现有为波束形成后的 I/Q，则明确处理级）及每束的发射模式、调制模板、采样率、采样起点、硬件延迟、通道延迟、发射和接收时间。锁定匹配滤波/脉压及子采样峰值估计，记录原 sample/beam/side/ping 与质量标志；区分一次峰值和旁瓣、多径、目标回波片段。不要拿去噪后的图像峰或模型暗场增益估计接收噪声。
2. 用独立测量的标靶三维坐标、接收/发射相位中心、姿态、杆臂和声速剖面生成参考 ToF。直达、同相位中心、近似均匀声速才用 $\tau\approx 2\rho/c$；若发射接收分置或路径弯曲，则应计算两段传播时间之和与其不确定度。空间坐标和深度基准统一。局部盐淡或声速明显分层时优先现场 SVP 或经验证的声线模型。海水声速计算可参考 [TEOS-10 的声速接口](https://www.teos-10.org/pubs/gsw/html/gsw_sound_speed.html)，海测交付/标定记录参考 [NOAA 水文测量要求](https://nauticalcharts.noaa.gov/publications/documents/HSSD_2026-0-00.pdf)，不是本实验自动遵循的认证标准。
3. 多距离同一时钟下，拟合 $\hat r-r_{\rm ref}=b+k r_{\rm ref}$；$b$ 会收纳时间零偏和参考坐标常偏，若已独立处理后者，则 $\delta t_0=2b/c_{\rm nominal}$。$k$ 表示声速比例和其它尺度项，在直线均匀、标称声速已知且无其它量程缩放时约为 $c_{\rm nominal}/c_{\rm true}-1$。单一距离不能分开尺度与时间零偏；还需电子自检的时间零位和同步日志区分硬件延时、导航时间插值误差。多靶、多航高、宽距离，同/反向和交叉航线配测。

## 2. 如何估计八类量

| 所需量 | 在有标签数据上的可执行估计 |
|---|---|
| 单次斜距偏差和方差 | 独立标靶参考减观测，对每束、舷、频率、距离、SNR、入射角分层；同时输出带偏差原始统计和去均值后的残差方差。硬件/相位误差应连同参考不确定度一起估计，不能全归因于接收器 |
| 两次斜距 $\rho$ | 用正确标靶身份、合法 token 建对，从看不到待测航次的标定模型生成残差 $(e_a,e_b)$；估计完整 2×2 协方差与相关，按航次/日或连续轨迹分块 bootstrap |
| 相邻 ping | 同侧、束、靶、稳定几何，按真实时间差和可见时间窗口做滞后协方差/交叉谱；不是用异步的序号差假定 5 Hz，也不能把相邻 ping 当独立样本 |
| 左右舷 | 共时钟、同标靶跨舷配对（或用两个独立已测目标隔离电子共模），固定方向/姿态及窗口，计算去时钟项前后相关 |
| 跨航次重复 | 同一物理目标必须有独立标注和参考位置，按日期、水层、航向、姿态及底图的先验关系分组；标定/测试按整艘航次拆分，不随机拆 ping |
| 声速与时钟共误差 | 在同航段引入共有 $\delta c,\delta t_0$，一阶量距影响约 $(r/c)\delta c + (c/2)\delta t_0$（符号随观测约定）。与外参相位中心、钟同步、环境漂移分别建随机效应或显式图变量 |
| 地图误差与空间相关 | 对独立测绘靶/地形控制点残差 $\delta L$，先查坐标配准/系统偏差，再按方位与距离做 2D 半变异函数，估计相关长度，对不达平台的方向报告未辨识。共同的 $\delta L$ 应从同一项传播到涉及该靶的两条原距，不能当作两个独立地图误差 |

完整联合模型可写 $\Sigma=R_{\rm receiver}+G\Sigma_\eta G^\top$；$\eta$ 包含地图、相位中心、垂向、声速与时延等共同量。若图中已显式估计某一误差，不能在量测噪声再计一次。对错配用独立身份标签的混合概率而非无限膨胀协方差。真实量测精度需要标靶参考的误差界和报告标定区间的非平稳性。

[估计器](../../../research/sonar_range_factor_v5/calibration.py)接受已经提取并绑定独立参考的米制原距，演示尺度/时间零偏分离、配对和块 bootstrap、地图半变异；未替未知二进制波形写一个未经验证的解析器。[合成自检](evidence/calibration_selfcheck.json)的已知负相关 −0.408，留出估计 −0.405、95% 块区间 [−0.442,−0.371]；这不是千岛湖实测，也不能用来否定或替换当前假设。实际方差、协方差和关联概率的采集资料见[缺项清单](MISSING_MATERIALS.md)。
