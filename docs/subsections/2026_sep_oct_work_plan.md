# 2026年9—10月重点工作计划

> 基线日期：2026年9月4日  
> 本文档是两个月工作的执行基线；如目标、传感器条件或验收口径发生变化，应同步更新本文档。

## 总体目标

### 9月目标

在嵌入式目标板卡上完成运行环境和算法部署，初步打通：

```text
版本与配置 -> 环境安装 -> 传感器数据接入/回放 -> 算法启动
           -> 定位与建图输出 -> 状态监测 -> 日志归档 -> 自动回归
```

月末预期成果：**初步完成板载算法部署链路**。

### 10月目标

完善海底仿真环境，分别验证海底地形地貌的绝对定位匹配和相对定位匹配算法。

月末预期成果：

1. 完成海底绝对定位匹配算法仿真验证。
2. 完成海底相对定位匹配算法仿真验证。
3. 形成《海底地形地貌匹配算法仿真报告》。

## 当前工作基线

已经具备：

- IMU、DVL、压力深度计、MBES和侧扫声呐仿真数据链路。
- FAST-LIVO2启发的水声惯性ESIKF、局部MBES地形匹配、侧扫强度匹配和回环后端。
- 完整、未经地理裁剪的USGS Monterey Canyon实测测深与背散射场景：
  `29.205 x 17.665 km`、`5842 x 3534`像元、5 m原始分辨率；缺测区保留为空。
- 侧扫直接匹配已使用逐点共注册XYZ的密集背散射、八帧运动补偿条带、严格因果参考、
  逐ping增益/偏置消元、锚点隔离和保守图因子；当前三随机种子消融未显示大且稳定的增益。
- 自建图内不依赖当前里程计搜索半径的描述子候选、MBES几何验证和图优化种子重访精配准。
- 可交互仿真画面、离线测试程序和基础ROS 2传感器接口。
- 当前自动测试共70项，并已通过完整海图Isaac无界面冒烟验证。
- 完整三维姿态的局部滤波；当前全局位姿图只优化`x、y、yaw`。

尚未完成：

- 面向目标板卡的独立SLAM节点、完整原始声呐消息和一键部署链路。
- 以外部地理配准先验海图为参考、而不是以在线自建图为参考的全地图绝对重定位。
- 真实DEM不同区域、不同初始误差和多随机种子下的重复长航程定量验证。
- 全局滚转、俯仰优化以及完整姿态误差统计。

数据边界：

- USGS数据提供实测海底高程以及A/B/C/D四套实测背散射栅格；后者来自不同设备、
  频率和编码，当前逐层1%—99%归一化后拼接，是实测空间纹理，不是统一标定的绝对目标强度。
- 当前侧扫ping并非原始海试记录，而是由上述实测背散射纹理、地形、入射角、传播损失和噪声
  共同生成的仿真观测；它可用于算法和接口验证，不能冒充真实声呐采集精度。
- USGS先验图当前用于生成仿真世界；SLAM强度前端仍匹配在线自建图。因此现有global SLAM是
  自建图回环优化，不等同于对USGS地理坐标的绝对海图重定位。
- 300 x 220 m解析场景三随机种子直接强度消融中，平均局部RMSE变化为-0.44%，平均全局
  RMSE变化为+0.97%，符号随种子改变；不得将其解释为稳定精度增益，也不得与完整实测场景
  或海试精度混为一谈。
- 完整实测纹理场景1.1圈同种子消融中，直接强度使局部RMSE改善1.11%，但最终优化全局
  RMSE恶化0.61%；当前结论仍是“局部有小幅帮助，未证明全局增益”。

### 10月验证指标

绝对定位匹配：

- 全局重定位成功率。
- 水平位置误差和航向误差。
- 从失位到恢复定位所需时间。
- 错误匹配率和置信度可靠性。
- 不同初始位置、航向偏差下的有效搜索范围。
- 平滑地形与特征明显地形的性能差异。

相对定位匹配：

- 相邻关键帧相对位置和姿态误差。
- 单位航程累计漂移率。
- MBES局部匹配成功率和残差。
- 回环检测准确率及错误约束数量。
- 滚转、俯仰和航向误差。
- 关闭全部侧扫、只用侧扫候选描述子、再加入直接强度约束的三级消融结果。

### 10月底验收条件

- 相对匹配和绝对匹配具有独立的可运行入口与配置。
- 绝对匹配不依赖真值位置或局部搜索半径才能找到候选区域。
- 至少覆盖测线、回访、失位恢复三类任务和多种地形区域。
- 使用多组初始偏差和随机噪声重复试验，并报告成功与失败边界。
- 实测DEM/背散射纹理驱动仿真、解析地形仿真及未来原始海试数据的结果分别呈现，
  不混合作为同一精度结论。
- 报告中的表格、曲线和结论均可由归档程序与配置复现。
