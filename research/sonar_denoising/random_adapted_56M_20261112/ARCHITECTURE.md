# 随机弧形条纹去噪模型架构

## 一、观测域和特征

NoFIRSonarMWCNN显式区分四类输入：公开显示图亮度、线性包络、公开复数SAS、声学所复数观测。图像和包络没有实测相位，相位特征必须为零，不能把显示图反构造为“实测复数信号”。

设幅度A=|z|，有效支持M=(A>0)，对数幅度q=ln(A)。无效点不参与对数和局部均值估计。网络的三个输入通道为：

1. 对数幅度的局部对比度：q减去5×65窗口的支持归一化均值。
2. 对真实复数观测，取沿距离相邻样点单位相位乘积u[j]·conj(u[j−1])的实部。
3. 上述相位乘积的虚部。

局部均值只构造特征，不替换原始输出基底。原幅度A保留。网络预测单通道Δ，恢复幅度为A_hat=A·exp(Δ)；如需复数形式，则保留原观测相位z_hat=z·exp(Δ)，这不代表恢复了未知的干净相位。

## 二、三层Haar卷积骨干

正式宽度w=96。输入边界仅补齐到8的倍数，最终裁回原高宽，没有几何超分、像素重复或非等比缩放。Haar变换将每个通道分为四个子带，空间宽高各减半；逆变换执行对应重建。

| 层级 | 空间尺寸 | 通道及操作 |
|---|---|---|
| 输入与域调整 | H×W | 3通道；四域各3个gain、3个bias，共24参数 |
| head、encode0 | H×W | 3→96；encode0膨胀率2、1 |
| Haar、encode1 | H/2×W/2 | 96→384个子带通道，再卷积为192；膨胀率1、2、1 |
| Haar、encode2 | H/4×W/4 | 192→768个子带通道，再卷积为384；膨胀率1、2、1 |
| Haar、middle | H/8×W/8 | 384→1536个子带通道，middle输出768；膨胀率1、2、3、3、2 |
| middle_out、逆Haar | H/4×W/4 | 768→1536→384，与encode2结果相加 |
| decode2、up2、逆Haar | H/2×W/2 | 384→768→192，与encode1结果相加 |
| decode1、up1、逆Haar | H×W | 192→384→96，与encode0结果相加 |
| decode0、tail | H×W | 96→1，输出Δ并乘有效支持M |

卷积核均为3×3，卷积阶段使用ReLU。tail权重和偏置零初始化，初始Δ=0，输出初始为恒等映射。第一步可先更新输出头，后续梯度再进入骨干；这不等于训练后的网络仍是恒等函数。

NoFIRSonarMWCNN参数总量为56,083,513，其中域嵌入24个参数。LargeSonarMWCNN.py里另一个同文件类含早期一致性聚合及门控结构，但不是本次正式模型实例，不能将其画进当前56M架构。

## 三、原生分块推理

infer_raw先在完整输入域上构造特征，再按核心窗口输出结果。默认核心96×768，窗口具有上下168、左右200的上下文预算，窗口起点对齐全局8像素Haar晶格，仅写回核心区。NX TensorRT部署曾采用192×768核心；核心尺寸是计算分块，不是测量分辨率。

此目录保留原PyTorch推理函数。TensorRT引擎和权重不随代码发布，不能把CPU合成测试当作在目标硬件完成精度或速度验收。

## 四、FIR运算与命名边界

“NoFIR”具体指不对接收观测施加本项目FIR_only带通去噪，也不对模型输出串接该滤波器。它不否认下列有限支持运算：

- 特征构造的5×65局部均值，是有限窗口的特征归一化。
- 人工噪声生成的33抽头色化核，只改变新生成噪声的频谱，不滤波作为训练参考的接收观测。
- Haar、小波CNN及卷积本身也具有有限支持。

声学所与公开资料可能已经有上游采集和处理，源观测不等于未经滤波的ADC信号，也不等于无噪声地形真值。
