# 随机弧形条纹模型训练过程

## 一、训练任务

本任务在已有观测z上生成额外条纹，构造observed=z+synthetic_noise，再以加噪前观测的对数幅度作为参考。显示图域按其范围处理饱和，不能将其与物理复数幅度等同。模型学习去除人工加入部分及其可迁移结构；由于z可能含真实噪声，训练并不拥有真实无噪声标签。

不将FIR_only输出当作干净标签，不先对接收观测进行本项目带通FIR。参考样本的上游处理历史仍需保留。实际训练数据路径经过脱敏，数据本身未发布。

## 二、预训练与适配

### 1. 数据构成

公开训练条目为558幅Gavia图像、4个长条包络条目、129个复数SAS条目，共691。公开验证包含32幅图像及4个包络条目。SAS采集组来源独立性不足，因此没有将该组当作独立测试集。数据出处及许可见records/training_sources_without_paths.json，发布代码不改变原数据许可。

本地适配有48个侧/波束训练条目和16个侧/波束验证条目。它们来自按物理数据段划分的8份单侧源阵列，每份8束；不是64次独立采集。预训练只使用公开训练源，适配采样顺序为4个本地样本后1个公开样本，验证组不参与优化器。

### 2. 更新与优化器

四进程DDP，每进程每步一个原生窗口，等效全局batch为4。一“步”是一次全局优化器更新，不是一次ping，也不是四次独立更新。

| 参数 | 预训练 | 适配 |
|---|---|---|
| 更新步数 | 24000 | 8000 |
| 全局样本暴露次数 | 96000 | 32000 |
| 初始化 | 新建同族网络，零输出头 | 加载预训练选中检查点 |
| AdamW初始学习率 | 1e−4 | 3e−5 |
| 权重衰减 | 1e−5 | 1e−5 |
| 梯度范数裁剪 | 1 | 1 |
| 学习率调度 | cosine，最低为初始的0.1倍 | 同左 |
| torch随机种子 | 20261108 | 20261108 |

训练禁用TF32，设置cuDNN确定性及非benchmark模式。固定种子并不保证所有平台和不同库版本按位一致，实际输入与检查点指纹仍需要核验。

### 3. 窗口和人工条纹

每次从源阵列取最大96×384核心，连同上下文及必要的左邻点；不缩放原生测量网格。随机弧形噪声采用全局坐标和种子，使整图与局部裁块可得到相同位置的扰动。

每侧随机1至3个有效图像触发源；位置可落在航段前后及距离轴外侧附近。源位置、间距、弯曲、相位、载波相位、峰宽和相对强度均随机化；相对噪声RMS在0.04、0.08、0.15、0.30、0.50、0.80中抽取。原图不发生几何变形，不另加独立明暗照明场。

支持掩码保护观测水柱和无效点，不向这些区域添加人工条纹；该掩码只控制人工增强，不作为事后把模型输出边缘涂黑的修补操作。约20%的训练样本为恒等样本，以约束不应改变的已有结构。

复数噪声的频谱由33抽头色化卷积塑造，跨波束相关性使用候选协方差。这个统计构造可能包含真实回波的影响，不能称为已经识别出的设备干扰源物理模型。

## 三、损失函数与验证选择

设目标对数残差为ln|z|−ln|observed|，预测为Δ，有效支持为M。fidelity_loss由三部分组成：

1. beta=0.1的逐像素Smooth L1残差损失。
2. 权重0.2的线性幅度相对误差项。参考能量仅用于损失单位归一化，不是输出亮度补偿。
3. 权重0.1的相邻有效点残差梯度L1项。

验证不更新权重，分别计算已知加噪恢复误差output_log_RMSE，以及恒等输入下模型造成的reference_change_log_RMS。选模分数是二者之和；选取分数最小的已保存检查点，分数相同时优先较早步数。不是简单按最后一次训练batch的loss选模型。

本次预训练选中24000步，SHA256为fe8552500fcf16b5c981c0274606063da4cdf096532d048c81f9b29c8fdc0a5f；适配选中8000步，SHA256为5aeb71e0bf53c9adecfb461a6cfd1bfd119ac6d15c01c2821508b9bbb8df0ff6。权重未公开，哈希只用于身份核对，不能用来推理。

完整检查点验证历史见records/validation_history.csv及两份阶段完成记录。验证恢复误差是对数幅度误差，不是分贝或定位米数；适配阶段固定验证窗口已经参与选模，不能再称为完全独立最终测试。

## 四、复训入口与数据准备

standalone/RunRandomRippleSonarTrial.py是原流程入口，包含数据准入、支持构建、两阶段训练和后续评估。它依赖受控的原始来源、已准备数组和处理元数据，不能只下载此代码后就恢复这些私有输入。完整输入契约见DATA_CONTRACT.md。

已自行准备合规输入时，首先在自己的实验根目录放置admission_manifest.json和random_ripple_profile.json。清单需要真实路径、形状、数据域、训练/验证组、来源指纹及当前文件大小/mtime；不能直接把脱敏来源表当可执行清单。路径及依赖检查通过后，原训练器的调用形式为：

```bash
python -m torch.distributed.run --standalone --nnodes=1 --nproc-per-node=4 \
  standalone/TrainNoFIRSonarDistributed.py --root /path/to/new_experiment \
  --phase pretrain --steps 24000 --width 96 --random-ripple

python -m torch.distributed.run --standalone --nnodes=1 --nproc-per-node=4 \
  standalone/TrainNoFIRSonarDistributed.py --root /path/to/new_experiment \
  --phase adapt --steps 8000 --width 96 --random-ripple
```

这些是有前置条件的调用示例，本次发布没有执行上述训练。正式复训应先用新目录和小步数smoke检查数据、梯度、支持掩码与验证组隔离；不能覆盖本次冻结检查点或省略原准入逻辑。改变数据或软硬件版本后，不能要求得到完全相同的权重哈希或指标。

## 五、训练记录的解释

records中的阶段摘要和输入审查保留实际更新次数、来源暴露、验证历史及检查点指纹，但不附完整私有输入或逐样本数据。因此可以审查过程与现有证据，不能仅凭这些摘要证明所有训练张量已被第三方重新生成。

已有记录明确real_quality_accepted=false：表示完成训练和数值评估不等于真实无噪声质量验收。模型实际有工程使用结果，但跨设备、跨海域和独立航次泛化仍需专门验证。
